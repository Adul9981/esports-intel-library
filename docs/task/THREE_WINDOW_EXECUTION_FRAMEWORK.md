# 四阶段执行框架（0-10 / 10-20 / 20-30 / 30+ 分钟）

> 候选执行节奏（主窗口讨论稿，2026-08-10 用户修正版）：0-10 小仓方向判断，
> 10-20 方向确定+决策，20-30 方向确定+决策，30+ 基本确定结果。
> 需用真实 1 分钟数据验证后落地。

## 1. 框架定义

```text
阶段 1（0-10 分钟）：小仓 + 方向性判断。
  信息最少、价格噪声最大；小仓或只记录信号，避免用噪声下重注。
阶段 2（10-20 分钟）：方向性确定 + 决策。
  —— 反转策略主窗口：深水区反转启动（落后方单局上穿 0.30/0.50，5-10 分钟窗口）；
     熟练度信号（阿卡丽单杀等）；一血/团战转折。
阶段 3（20-30 分钟）：方向性确定 + 决策。
  —— 顺势加仓 / 减仓窗口：热门/领先侧连续压制（价格持续 >0.65 且不回撤）则顺势；
     彩票策略可开始考虑（25 分钟后）。
阶段 4（30 分钟之后）：基本确定结果。
  —— 锁盈 / 止损窗口：方向大概率已定，但尾盘反转（BLG 93c->0、BRO 98.5c->0.05c、
     K27 6c->100c）集中发生在 30 分钟之后——"基本确定"不等于"可以不动"。
```

## 2. 评估（哪里对，哪里要改）

```text
对的地方：
1. 0-10 小仓方向判断——信息最少、波动最大（08-04 起多笔前 10 分钟重仓亏损佐证）。
2. 10-20 反转主窗口——与已验证的中段信号一致（K27 Map2 深反启动、
   CFO G3 阿卡丽单杀、DK G2 深水区 17:13）。
3. 25+/30+ 彩票窗口——极值低点（<10-15c）多出现在后段（K27 整场 6c、BRO 1.5c、
   WE/AL 0.65c 均在中后段），彩票放后段符合"极值出现在后段"的直觉。
4. 30+ 基本确定结果——多数场次方向已定；但尾盘反转集中在这里，
   因此 30+ 同时是锁盈/止损窗口。

待验证/风险点：
1. "10-20 决策"必须绑定信号模板，否则退化为"感觉反了/顺了"（08-09 群聊噪音翻版）。
2. 彩票（25+/30+）低点多数是死亡螺旋（B4 直线阴跌），必须加"启动确认"
   （价格上穿 0.2/0.3）过滤，否则是接刀；彩票仓=归零预算。
3. 阶段边界（10/20/30 分钟）是粗略假设，需用真实局内时间对齐验证。

## 盲点清单（用户未提及，v1 回测补充）

```text
1. 对齐误差本身：开局检测是启发式（±5 分钟），结果对对齐方法敏感；
   CS2 长窗口序列 v1 无法对齐（待事件级时间戳）。
2. 市场结构差异：BO3 第三局没有独立小局市场（只有 Moneyline）——
   "20-30 分钟决策"在第三局只能在 Moneyline 上做，窗口定义不同。
3. 可成交性/流动性：8c 彩票价可能买不到或滑点巨大；回测用中间价会高估收益，
   必须加成交量过滤。
4. 样本偏差：现有快照偏爆冷/深反（t=0 方向一致性 36% < 随机 50%），
   回测系统性高估反转机会——结论只用于验证方向，不用于定仓位。
5. 决策模板的"不做"分支：10-20 未触发信号时正确动作是不做；
   回测要统计"遵守信号会错过多少机会"（机会成本 vs 避免接刀）。
6. 赛制/比赛性质是协变量：表演赛（KeSPA）、训练赛的打满率/反转率与正赛不同
   （正是"Over 2.5 表演赛"那单的逻辑）——需按赛制分层。
7. 游戏差异：LOL ~30-40 分钟/局、CS ~25-35 分钟/图、DOTA ~40-50 分钟/局，
   10/20/30 边界应按游戏校准，不是通用固定值。
8. 价格≠概率：前 10 分钟价格是情绪/流动性驱动，可能系统性偏
   （热门被过度定价/爆冷被低估）。
9. 锁盈的收益代价：30+ 锁盈能防 20% 尾盘反转，但也会少赚"继续涨到 100"的部分；
   需回测"锁盈 vs 不锁盈"的期望差，而不是只防风险。
10. BO3 内部分局处理：G1 无前史、G2 携带 G1 结果信息、G3 决胜局情绪最极端，
    窗口信号应按局次分层（同局次内做统计）。
```

## 3. 真实数据验证方案（1 分钟 CLOB 数据可支持）

```text
能力现状：Polymarket CLOB /prices-history 可取 1 分钟粒度（已用于 DK/KT、CFO、
BFX/DRX、K27、FNC/KC 等快照）；bar_monitor_runner 可做盘中实时监测。

步骤：
1. 为每场已入库比赛标注"局开始时间"（从价格序列检测启动点，或从赛程时间对齐）。
2. 对每个 Game X 市场取价格序列：t=0/10/20/30 分钟的价格与方向。
3. 验证三条假设：
   H1 0-10 分钟：t=10 的价格方向与终局一致性低（噪声大）。
   H2 10-20 分钟：反转启动/压制确认信号出现后，后续胜率显著提升（对照无信号组）。
   H3 20-30 / 30+：t=20/30 的价格方向与终局一致性高（>85%）；
      统计"30 分钟后尾盘反转"频率（衡量 30+ 锁盈窗口的风险）。
   H4 彩票时机：极值低点（<10c）出现时间分布——是否集中在 25 分钟之后。
   H5 让一追二分层：G1 输家整场最低 <=12/20c 后赢下系列的频率与期望，
      按 赛制 x 赛前强弱区间 x 游戏 分层（登记于 STRATEGY_RESEARCH_HANDOFF 未决问题 9）。
      定价逻辑：命中率约 30%（非高胜率）> 盈亏平衡 12-20% -> +EV（中胜率高赔率 5-9x）。
4. 输出：每窗口的命中率矩阵 + 尾盘反转率，决定三窗口的仓位上限与信号模板。

样本：已有快照（DK/KT、CFO G2/G3、BFX/DRX、K27、FNC/KC、WE/AL、BLG/TES、
NS/DNF、T1/HLE、SK/NAVI、CS2 系列等）+ 每日新比赛实时采集。

注意：快照窗口含赛前/赛后，粗算"低点距终局"会失真（已踩坑）；
必须先把序列对齐到"局开始时间"再统计。
```

## 4. 落地顺序

```text
1. 先跑假设验证（用现有快照，1-2 天内可出第一版矩阵）。
2. 通过后把三窗口写成执行模板（每窗口仓位上限 + 信号模板 + 锁盈规则）。
3. 接入自动扫描（TASK2_AUTOMATION_CANDIDATE_FLOW 三层框架），
   实盘仍走 dry-run -> 小额实盘 -> 风控红线（autopilot 默认关闭）。
```
