# 四阶段执行框架回测 v1（2026-08-10）

> 数据：已入库 LOL 快照 28 条局级序列（1 分钟粒度，8 场比赛双/单边）。
> 方法：价格序列"开局检测"（基线偏离法）对齐局开始时间，t=0/10/20/25/30 分钟取价。
> 局限：v1 仅 LOL（CS2 长窗口对齐不可靠，待事件级二次对齐）；开局检测为启发式，
> 存在 ±5 分钟误差；成交量未纳入（回测用中间价，会高估可成交性）。

## H1/H3：方向一致性（价格>0.5 与最终胜者一致）

| 局内时间 | 一致性 | 解读 |
| --- | --- | --- |
| t=0 | 36%（10/28） | 赛前价在这批样本里经常"反着走"（样本偏爆冷）→ 前 10 分钟不下重注 |
| t=10 | 57%（16/28） | 仍是掷硬币 → 0-10 阶段噪声大，方向未形成 |
| t=15 | 64%（18/28） | 方向开始成形 |
| t=20 | 68%（19/28） | 10-20 是"方向成形窗口" |
| t=25 | 79%（22/28） | 快速收敛 |
| t=30 | 81%（21/26） | 基本定局 → 30+ 是"锁盈/止损"而非"新决策" |

**结论：四阶段划分基本成立**——0-10 噪声（57%≈掷硬币）、10-20 方向成形
（57%→68%）、20-30 收敛（79-81%）、30+ 定局。

## H4：深水区（min<15c）低点出现时间

```text
低点出现时间：中位数 29 分钟，范围 5-38 分钟；>25 分钟占比约 60%（13/21）。
→ 支持"彩票策略放 25 分钟之后"：极值低点多出现在后段（死亡螺旋或最后翻盘都在这里）。
```

## H2：反转样本触发时间（需 v2 修正口径）

```text
v1 用"首次上穿 0.50"，被开盘前交叉污染（多个负值/过早值），不可靠。
v2 口径应为"深水区低点之后最后一次上穿 0.30/0.50"。
已知正例（低点后的实际反转触发）：DK G2 ~17 分钟、CFO G2 ~20 分钟、
K27 Map2 ~17-20 分钟、TES G1 ~19 分钟、WE G2 ~27 分钟 → 反转触发集中在 15-30 分钟。
```

## H3-风险：尾盘反转（高位 85c+ -> 终局 <=20c）

```text
高位样本 15 个，尾盘反转 3 个 = 20%（BLG G1 95.5c->0、BFX G1 98.5c->0、NS G1 97.5c->0）。
反转发生时间均在局内 26-33 分钟——正是"30+ 基本定局"的窗口。
→ 30+ 阶段不是"结果已定可以不动"，而是必须挂锁盈/止损（D2/D3）。
```

## 样本偏差警示

```text
t=0 一致性仅 36%（低于随机）：因为现有快照集中在"用户关注的爆冷/深反场次"。
回测结果会系统性高估反转机会；结论用于"验证方向"，不用于"定仓位"。
需补全量随机采样后再定仓位上限。
```
