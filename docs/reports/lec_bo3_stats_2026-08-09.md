## 数据与方法

- 数据源：Polymarket gamma API 分页拉取全部 LEC BO3 事件，共 69 场（2026-02-21 → 08-08 创建的赛事）。
- 已结算：65 场。排除 4 场未结算赛事（08-09 FNC/KC、TH/G2；08-10 SK/VIT、NAVI/G2），避免把"当前行情"误当结果。
- 判定方法：
  1. 取每个事件 Game 1 / Game 2 / Moneyline / O/U 2.5 市场；
  2. 只有 outcomePrices 含精确 1/0 才视为已结算；
  3. G1 赢家 == G2 赢家 → 横扫 2:0；G1 赢家 != G2 赢家 → 打满 2:1；
  4. Moneyline 判定最终系列赛赢家。

## "G1 强队赢 → G2 送弱队"验证

### 已确认口径（用户）

- SK/NAVI 08-08 计入：G1 NAVI（赛前 61.5c 热门）赢 → G2 SK（38.5c 下狗）赢 → 打满 → NAVI 赢系列赛。
- T1/HLE 为强强对话，不计入"强队送弱队"。

### 结构性事实

- **打满 ⟺ G2 赢家 ≠ G1 赢家**（65/65 验证）。因此"G2 送给 G1 输家"在打满场次里是 100% 必然事件，问题只在"这场会不会打满"。
- 打满率 49.2% 意味着：G1 结束后买"G1 输家赢 G2"，从结构上看约一半场次必然命中（命中即拿 G2 全价）；另一半横扫则归零。真正的交易价值取决于 G2 买入价相对 49% 命中率是否便宜。

### 数据缺口

- 以"开赛前 1 小时价格"为赛前强弱：**07-24 之后 18 场全部可取**；更早（05-09/05-10 及之前）Polymarket prices-history 为空，无法重建赛前强弱。
- 近 3 个月 22 场中 4 场无法判定强弱，其中 3 场是打满（05-09 KC/MKOI、05-10 MKOI/G2、05-10 KC/GX）——若补齐赛前价，样本还可能增加。

## 交易含义与待办

1. **LEC 打满率 ≈50%（近 3 个月 54.5%、全量 49.2%）是可用基线**：作为"G2 买 G1 输家小翻倍"的赔率锚点。若 G2 下狗价格显著低于 49c（例如 30~40c），历史结构支持正期望假设，但需用实时数据回测确认。
2. **强弱维度实时采集继续**：近 3 个月已从赛前 1 小时价回补 18 场（送弱队 4/18），下一批数据继续累积，目标样本 ≥30 场再出结论。
3. **队伍打满倾向可作辅助过滤**：Fnatic/MKOI/VIT 场次优先关注打满结构；G2/TH 场次降低预期。
4. 与任务 6 情报库对接："LEC 常打满"信号状态从弹幕情报（低置信）升级为统计基线（中置信）。
