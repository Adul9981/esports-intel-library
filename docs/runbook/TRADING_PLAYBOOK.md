## 一、赛前 6 问（开赛前 10 分钟过一遍）

```text
1. 赔率结构：五五开（45-55c）/ 三七开 / 大热门？
   -> 五五开：可小仓早买（预算 <=30%，50-60c，>60c 不追）🟡
   -> 三七开：买 3 侧 30-40c 小底仓 🟡；买 7 侧禁止（负期望）🔴
   -> 大热门（>=75%）：不赛前追高，只等赛中回撤
2. 队伍画像：BLG 大优会浪（90c+ 不持仓）；TES/BRO 低位反转执行者（留意深蹲）；
   TT 爱打架（下狗反转早买区 35-45c）。
3. 边际信息：有信息差（假赛感 / 阵容 / 状态 / 事件）-> 可正常仓位；
   纯信心 -> 按 D5 彩票仓（<=10-20%）。
4. 市场层：小局（Game Winner）还是整场（Moneyline）？第三局起只有 Moneyline；
   仓位、止损、复盘按市场层分开记账。
5. 可成交性：成交量 >=5 万、spread <=6c、深度 >=2x；不达标跳过。
   热门无回撤场次（最低 62-82c）= 低交易价值，挂单不触发 = 正常，别硬做。
6. 预期情景：按 docs/runbook/PREDICT_SCENARIOS.md 列 3-5 个可能走势
   信息差检查：首发/阵容/二队构成（杯赛是确定性事件，DNS 18.5c->66.5c 一分钟 3 倍；提前小仓埋伏信息差标的）
   （S1 压制=网格不挂单，大热门 >=80c+画像确认可躺赢持有 / S2 回撤 45c / S3 深蹲反转 / S4 尾盘 D2 / S5 开局碾压不早买）；
   LCP/LEC 波动大 -> 单局快进快出、95c 止盈优先、不延伸整场（联赛画像见 LEAGUE_PROFILES）。
```

## 三、铁律（不做清单）

```text
追高 >80c（一票否决）；接飞刀（无反弹确认的低吸）；决胜局中位重仓；
全仓（任何情形）；同一小局双边都买；预期落空后仍按预期重仓；
止盈后剩余仓位不重新挂保护单；<b>反弹确认拉到 70-80c 不等于反转确定</b>
（T1 vs HLE G2：16.5c→78.5c→0.05c，反弹确认后必须跟止损）；
<b>假赛疑似（明眼局）不参与</b>（LEC/LPL：干净翻转无法从赔率证伪，需弹幕/主播信号交叉验证）；
<b>反转日纪律</b>：连亏 2 笔强制减半、D6 到线只看不开、高位（90c+）不追。
<b>信息自检</b>：这笔单和我的第一判断一致吗？不一致不下；群聊观点必须市场验证（BFX/DRX 案例）。
<b>让分不是保险</b>：DRX +1.5 赛前 74.5c 横扫照样归零——让分一律按归零预算。
<b>高赔率池纪律</b>：不因一次 16 倍放大仓位（FNC/K27 教训）；稳定池亏损不挪用高赔率池翻本；
  深水区反转等"启动确认"（单局上穿 0.3/0.5）再进，不接最低点。
<b>加仓纪律</b>：逐笔加仓时现价高于成本即停（DRXC G2 70c 加到 300+ 反面）；全仓赢不改变全仓风险（DNS G3 案例）。
```

止损单挂交易所级（脚本会崩，挂单不会）；当日已实现亏损到 D6 线即停新开仓。
