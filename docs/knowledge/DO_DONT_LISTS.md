# 正面 / 负面清单（DO / DON'T）

最后更新：2026-08-11

用途：复盘闭环的对照表——每笔交易复盘先打开本清单打勾，**做对的反复强化、做错的硬拦截**。
清单随样本增加持续更新；被数据推翻的经验移入文末"已被数据推翻"区（保留记录不删除）。

维护规则：

```text
1. 每笔复盘命中 DO 项 -> 计数 +1，连续命中 -> 维持/升级该打法仓位；
2. 每笔复盘命中 DON'T 项 -> 计数 +1，同一项连续 >=2 次 -> 强制当日降级/停该类交易（D6 联动）；
3. 新案例 -> 更新对应项与样本；样本 >=10 且方向稳定 -> 并入 EXPERIENCE_INSIGHTS 已确认区。
```

## 三、复盘对照流程

```text
1. 每笔复盘（TRADE_REVIEW_TEMPLATE）先填"命中的 DO / DON'T ID"；
2. 命中 DO -> 计数 +1；命中 DON'T -> 计数 +1；
3. 同一 DON'T 连续 >=2 次 -> 当日强制降级/停该类交易；
4. 每月汇总：DO 命中率上升 / DON'T 重复率下降 = 项目在进步；
5. 样本 >=10 且方向稳定 -> 并入 EXPERIENCE_INSIGHTS 已确认区。
```

## 四、与其他文档的关系

```text
DO_DONT_LISTS  = 复盘对照的"操作清单"（本文件）
EXPERIENCE_INSIGHTS = 已确认经验的"结论库"（样本 >=10 沉淀到那里）
PSYCHOLOGY_NOTES = 心理模式的"原因库"（N14-N17 的深挖）
TRADING_PLAYBOOK = 盘中速查的"执行表"（正面打法 + 铁律）
```
