# 预期情形盘中验证（情报层闭环）

最后更新：2026-08-08

定位：赛前情报（TEAM_PROFILES 队伍画像 / 预期情形）只是**假说**；
盘中用可观测信号确认或否定，再决定仓位上限与形态路由。
防止"预期"变成"信念"（08-04 HLE 昨日 2:0 → 次日 77c 重仓的教训）。

## 模板

```text
预期：队伍 / 情形 / 形态倾向（来源：TEAM_PROFILES 或赛前分析）
验证信号（必须可观测）：时间 + 价格 + 事件（90c+ 停留时长、经济差、送头、团战胜负等）
确认 → 行动：上调仓位上限 / 启用对应策略 / 调整锁盈优先级
否定 → 行动：降级为纯信心（D5 小仓）或跳过；预期落空必须记录
```

## 示例

### 1. BLG：大优会浪 / 送（B1 尾盘崩塌倾向，信任高）

```text
验证：90c+ 停留 >8 分钟 / 经济领先 >=1 万 / 资源不控或送头事件
确认 -> D2 强制锁盈（75-85c 锁 80%），不持仓过 90c+
否定（持续滚雪球压制）-> 正常持有
```

### 2. TES：低位反转执行者（A1/A2 倾向，信任中）

```text
验证：深蹲 <10c + 单根 +10c 反弹确认 / Moneyline 低开 35-45c 早买区
确认 -> 彩票机器层 2 或 P5 早买（35-45c）
否定（死亡螺旋信号：无反弹阴跌 / 破前低 / 流动性干涸）-> 不接
```

### 3. TT：爱打架 / 下狗反转倾向（A4/C2 倾向，信任中）

```text
验证：G1 早期快速缩距（C2 早期缩距）/ Moneyline 从低开抬升
确认 -> P-早建仓 35-45c 早买
否定 -> 跳过
```

### 4. BRO：经济劣势但翻盘能力强（A1 倾向，信任中）

```text
验证：落后但英雄阵容有翻盘工具 / 诱因是单次团战失误而非整局崩盘
确认 -> S1-深反彩票（小仓）+ 反弹确认
否定 -> 不接（深蹲判别器死亡螺旋清单）
```

## 对接规则

```text
TEAM_PROFILES 信任等级驱动验证强度：
  高信任（盘面实锤多笔）-> 可提前半仓，盘中验证做确认；
  中信任（单笔实锤 + 用户观察）-> 必须等盘中信号确认才给正常仓位；
  低信任（用户观察待验证）-> 只能按 D5 彩票仓，等确认后升级。
预期落空记录回 TEAM_PROFILES（信任等级下调），形成画像自校正闭环。
```
