## 用法

```text
赛前情景规划：先查本联赛波动/打满/信誉 -> 定仓位修正与情景权重
  （LCP/LEC 高波动 -> 单局快进快出，止盈 90-95c 优先，不恋战 G3/不延伸整场）；
形态路由：LCK/CS2 反转可信可正常仓；LPL/LEC/LCP 同形态降级小仓或观察。
```
