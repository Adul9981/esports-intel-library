# 情报信号库（解说/主播/官方信息 -> 结构化信号）

用途：把直播/解说中的关键信息转成可验证的信号，入库并与市场、结果对照。
来源分级：解说（职业选手转型，可信度高）/ 主播 / 官方 / 社区 / 直播弹幕（观众，低置信度，仅作观察登记）。

> 机器可读权威源：knowledge/intel_signals.json（schema：schemas/intel_signal.schema.json）。
> 本文件是人读摘要；录入/回填请用 tools/record_intel_signal.py，模板见
> knowledge/INTEL_SIGNAL_TEMPLATE.md，可信度统计见 tools/intel_stats.py。
> 设计文档：docs/task/INTEL_SIGNAL_LIBRARY_PLAN.md（含规划层技术点）。

字段：

```text
日期 / 比赛 / 信号内容 / 对象（队伍/选手）/ 方向含义（利好哪侧）/
可信度 / 采集时间（赛前/赛中）/ 市场验证（采集前后价格变动）/ 结果（是否应验）
```

## 规则

```text
1. 职业选手转型解说的关键信息（英雄熟练度 / 阵容克制 / 选手状态 / BP 意外）优先入库。

3. 赛后回填"是否应验"，按来源分级累计可信度统计。

```
