家族标签（反转类 A / 崩塌类 B / 震荡类 C）保留，但章节按市场层级组织。

术语统一（2026-08-08）：

```text
- 下狗（underdog 音译）= 赛前不被看好、赔率低的那一方（TT、TES、BRO、VG/YB）。
- 落后侧 / 下盘 = 盘中暂时落后的一方（不区分赛前身份；如 Liquid 盘中 16.5c 是"落后侧"，不是"下狗"）。
- 用法：A4 用"下狗"（赛前身份）；深蹲判别器用"落后侧/下盘"（盘中状态）。
```

## 三.5 深蹲判别器（快速反弹 vs 死亡螺旋）

目标：区分"快速反弹型深蹲"（可接）与"死亡螺旋型"（躲开），避免把接刀当深反。

深水区反转启动确认（CS2，2026-08-10 入库，FNC vs K27）：
  BO3 落后方在 Map2 中段跌至 <=15c（整场 <=8c），随后 5-10 分钟内单局上穿 0.3/0.5
  = 启动信号；整场 6c->100c（16 倍）、Map2 11c->100c（9 倍）；CS2 下狗让一追二 = 打满（O/U Over）。

快速反弹型深蹲（接，彩票仓 + 反弹确认）：

```text
1. 低点后 5-10 分钟内出现首次有效反弹（单根 +10c 或相对低点 +50%）；二次探底不破前低。
2. 触底发生在比赛窗口中后段（20-30 分钟触底窗口是唯一正 EV 区间），距终局仍有时间。
3. 盘口流动性保持（spread 不放大、持续成交）；对手未持续滚雪球（对方价格未锁 90c+）。
4. 局内语境：下盘被砸的诱因是单次事件（一波团战/回合失误）而非整局崩盘；
   解说/阵容显示落后方仍有翻盘工具。
```

死亡螺旋型（躲开，不接）：

```text
1. 无有效反弹的持续阴跌；二次探底破前低并创新低。
2. 低于阈值持续 >20-30 分钟仍未修复；或临近终局才深跌。
3. 盘口流动性干涸（spread 拉大、价格长时间不更新）；Moneyline 同步死亡。
4. 反例清单：B3 假反弹（反弹后破位归零）、B4 直线阴跌、终局深跌、同一小局双边都买。
```

过滤顺序：

```text
先认形态（A1/A6 vs B3/B4）-> 再叠加"触底时机 + 时间剩余 + 流动性 + P5 上下文"。
```
