# 策略体系与执行规则总览

最后更新：2026-08-07

策略名称（v2.1）：**中位80（Mid80）**——中位入场、80% 成本回收、20% 彩票。
子形态：Mid80-S2（主攻，45c 档热门回撤）/ Mid80-S1（辅助，25-35c 中位小仓）/ Mid80-早买（模块，50-55c 一档 + 40-50c 回撤补）。

用途：把分散的现象观察、策略模板、执行模块整合成一套可执行、可自动化的策略体系。
细节以 STRATEGY_PATTERN_LIBRARY.md 与 config/strategy_templates.json 为准，本文件是执行入口级总览。

## 1. 体系结构

```text
现象层 P1-P6（只描述市场在发生什么，不下单）
  -> 策略层 S1-S4（怎么买、怎么卖、怎么管仓位）
  -> 执行模块（P-早建仓 / D2 锁盈 / D3 止损 / D4 进场三件套 / D5 信心溢价仓位 / D6 每日回吐）
  -> 执行管线（发现 -> 路由 -> 计划 -> 执行 -> 监控 -> 退出 -> 复盘）
```

## 2. 当前启用范围（2026-08-07）

主攻中位：

```text
S1-标准：20-50c 中位反转（保守版）
S2：40-50c 热门回撤（赛中回撤才买，不追高位）
P-早建仓：50-60c 开局/领先确认早买
```

统一操作模式（买80回收）：

```text
中位入场（如 30c）-> 60-70c 卖出约 80% 成本份额（回收本金 + 锁利）-> 剩余 20% 成本当彩票。
算例（$100 @ 30c = 333 股）：60c 卖成本 $80（267 股）-> 回款 $160（保底 +60%）；
剩余 67 股到 100c -> 总 $227（+127%）；剩余归零 -> 总 $160（+60%）。
```

暂缓（设计保留，不删）：

```text
S1-深反（<15c 彩票类）、环节 4 彩票机器、S3 实验、S4 持仓管理（仅建议）。
```

组合示例（2026-08-07 确认）："赛前买一部分"= P-早建仓模块 + 主策略（S1-标准 / S2），
不是独立策略。流程：开赛前 P-早建仓买 <=30% 预算（50-60c）拿入场资格 -> 赛中按价格区间
路由到 S1-标准（20-50c）或 S2（40-50c）接力 -> pre-position 与策略新仓分开记账，D2 统一锁盈。

## 4. 执行管线

```text
发现（任务 2 扫描器，待验收）-> 路由（方向 + 价格区间 -> 模板）
-> 计划生成（半自动：开赛前定策略）-> 执行（D4：先挂止盈/止损/彩票上限再买入）
-> 监控（D3 状态机，10-30s 轮询 + CLOB 最新成交价）
-> 退出（交易所休息挂单 + D2 锁盈 + 回撤保护）
-> 复盘闭环（knowledge/reviews + trades JSON）。
```

架构原则：

```text
1. 监控管状态、挂单管退出（脚本会崩，挂单不会）。
2. 数据用 CLOB 最新价/盘口（10-30s），不用 gamma 滞后价，不用 1-2 分钟轮询做退出。
3. 半自动优先，autopilot 全自动需显式开启且仅限 S1-标准/S2。
```

## 5. 半自动确认边界（2026-08-07 用户确认）

```text
- 开赛前（或开赛前几分钟）确定交易策略：需要用户参与（方向 / 价格区间 / 预算）。
- 策略确定后：买入、监控、挂止盈全部自动，无需再确认。
- 挂止盈完全不用确认。
- 主动平仓仍需用户明确表达（红线）；计划内自动止盈/止损除外。
```

## 6. 止损规则（2026-08-07 确认）

```text
- 中位止损：跌破成本一半离场（30c 入场 -> 15c 离场，亏损 50% 封顶）。
- 配套：比赛末段（最后 5 分钟）仍未反弹 -> 离场。
- 原则：止损价值在早不在晚（30c 入场 20c 离场少亏约 67%）；
  止损单进场即挂（D3 + D4），决定在事前，不在事中。
```

## 7. 风控与预算

```text
- 单场默认 <=80 USDC（config/risk_limits.json：单市场 80、单日 200、并发 3；验证后可升 100）。
- 全仓/超限：需在策略确认时显式指定金额并触发风控提示，不做系统默认。
- 昨日赛前 50-50 全仓（手动）靠运气拿到结果，标记为高风险行为样本：
  全仓 = 硬币翻转，不进入系统默认路径；如确要全仓，必须显式确认且通过 D6 检查。
- D6：当日已实现亏损超线停止新开仓。
- 三池原则：稳定池（S1-标准/S2/P-早建仓）+ 彩票池（暂缓的深反，占总资金 10-20%）。
```

单场预算档位测算（买80回收模式：中位入场 -> 70/80c 卖出 80% 成本 -> 20% 彩票到 100c）：

收益率（%）只取决于入场价与卖出价，与预算无关；预算只放大绝对金额。

| 入场价 | 70c 卖出（到100 / 保底） | 80c 卖出（到100 / 保底） |
| --- | --- | --- |
| 30c | +153% / +87% | +180% / +113% |
| 35c | +117% / +60% | +140% / +83% |
| 40c | +90% / +40% | +110% / +60% |

预算 70 / 80 / 100 的绝对收益示例（30c 入场、80c 卖出）：

```text
预算 70：到 100c 总回款 $196（+126）；保底 $149（+79）
预算 80：到 100c 总回款 $224（+144）；保底 $171（+91）
预算 100：到 100c 总回款 $280（+180）；保底 $213（+113）
```

对应止损（跌破成本一半离场）的损失：

```text
预算 70 / 80 / 100 -> 止损损失 35 / 40 / 50。
预算越大，收益和损失同步放大；若单场上 100，单日 200 额度下并发最多 2 场（3x100 > 200）。
```

## 10. 策略清单与收益率评估（2026-08-07 定稿）

已定稿策略共 3 个（其余暂缓：S1-深反、S3、S4）：

```text
1. S1-标准：20-40c 中位反转（保守版），买入 40/32/25/20c，止盈 55/70/82 + 15% 彩票。
2. S2：40-50c 热门深回撤，买入 50/45/40c，止盈 62/75/88 + 10% 彩票。
3. P-早建仓：50-60c 早买模块（与 S1-标准/S2 组合），50-55/56-60/40-50 分三档，跟随 D2。
```

| S1-标准 | 32c | 70c | +75% | +138% |
| S1-标准 | 25c | 70c | +124% | +204% |

| P-早建仓 | 50c | 70c | +12% | +52% |

可实现性（17 场电竞市场，价格穿越入场价的触发率）：

```text
20-35c 入场：11/17 = 65%    40c：10/17 = 59%    45c：12/17 = 71%
50c：10/17 = 59%            55c：11/17 = 65%
```

结论：

```text
- 深位入场（20-30c）收益率最高（保底 +120~180%），但只在约 65% 场次触发，
  且触发后止损率高（08-05 样本 73-91%）——只适合"明显弱方 + 时间充足"的小仓选项。
- S2 45c 档触发率最高（71%）、收益率可接受（保底 +10~56%），建议主攻。
- P-早建仓收益率最低（+2~28% 保底），价值是"拿入场资格"不是收益率，仓位小。
- "有的策略实现不了"的真实含义：热门场次（如 NRG/T1A/BESTIA）价格全程不下到 20-40c，
  深位/中位反转策略不会触发——这是入场条件天然筛选，不是策略缺陷。
```
