# 彩票机器（环节 4）策略定义与验证

最后更新：2026-08-08

定位：**不是预测哪场会发生奇迹，而是"全程覆盖 + 价格触发 + 自动执行"**。
识别 = 奇迹正在发生的几分钟内刚好在场、单子已挂好。
本质：多触发、小仓位、高赔率、统计期望，不追求每把都赢。

数据现实（为什么是小仓位）：

```text
深跌里大部分是死的（08-05 九连负；本轮回测 21 条深跌段中 4 条直接归零）；
只有靠"反弹确认"提高命中率 + 低档位倍数，才有正期望。
```

## 1. 两层触发

### 第一层：极低价彩票挂单（自动覆盖）

```text
触发：价格曾 >=25c，现跌入 <10c，且非终局（BO3 Game/Moneyline 市场）。
挂单：8c:$5 / 6c:$6 / 4c:$8 / 2c:$10（每档 $5-10，只有真跌到才成交）。
性质：归零在预算内可接受；成交后不主动挂普通止盈，等反弹由第二层接管。
```

### 第二层：反弹确认加仓（不接刀）

```text
触发（2026-08-08 回测定稿）：
  主触发：单根（1 分钟）拉升 >=10c 且起点 <10c（如 0.65c -> 13c）。
  备选  ：收盘首次 >= 段低点 +15c（触发更多但入口偏晚，假反弹风险高）。
  弃用  ：单根 >=15c（入口已到拉升顶，实测负期望）。
加仓：$15 确认仓，立即挂 50c:$6 / 70c:$4.5 / 85c:$3 分档止盈 + $1.5 彩票仓。
止损：跌破确认仓入场价一半 -> 离场（把 -100% 压到 -50%；
  代价是偶尔被洗出去——HLE Moneyline 案例已记录）。
```

## 2. 过滤条件（不满足不触发）

```text
1. 流动性：盘口深度足够，防 1c/99c 假数据。
2. 时间剩余：接近终局不触发（末段低吸默认彩票仓化）。
3. P5 上下文：BO3/BO5 落后方、系列赛仍有翻盘时间优先；
   整场 Moneyline 的深反比单局更值钱（翻盘窗口更大）。
4. 人工叠加（可选）：比赛阅读（假赛感 / 阵容 / 节奏）作为边际信息，
   只允许上调仓位档位，不允许改变止损与止盈纪律。
```

可成交性参数化（点 4，2026-08-08）：

```text
- 成交额下限：单市场 24h 成交量 >= 5 万 USDC（低于此值数据/执行双打折，如 Liquid vs fnatic 5.3 万）。
- 盘口深度：挂单价位附近 3c 内深度 >= 挂单金额 x2。
- spread：<= 2-3c；滑点预算：入场 <= 1c、保护触发 <= 3c。
- 深反极低档（2-5c）在薄盘可能不成交或成交极慢，按"可成交性评分"降级或跳过。
```

## 3. 回测结论（2026-08-08，全量 1 分钟数据）

```text
详见 reports/lottery_machine_backtest_2026-08-08.md。
- 层 1：反转场次平均吃 8.3x（WE G2/BRO G1 29.7x），死场预算内归零（4/21）。
- 层 2（单根 +10c）：4 次触发，平均 +13.7/笔（ROI +91%），50/70/85 命中 2/2/2。
- 层 2（累计 +15c）：7 个去重触发，平均 +14.9/笔，但含 2 个假反弹负样本（HLE -48.9%）。
- 结论：彩票机器两层结构成立，主触发定为"单根 +10c"；
  下一步小额实测 20-30 个触发样本（环节 4 验收标准）。
```

深跌基准率（28 个市场侧样本，低点 <=20c 的 21 个）：

```text
- 反弹到 50c：43%（中位 16 分钟）；到 70c：43%（20 分钟）；到 100c：38%（27 分钟）。
- 彩票机器的"反弹确认"层吃的就是这个窗口：约 4 成概率回到 50c+，中位 16 分钟，
  配合低档倍数（<20c 进场）构成正期望的前提。
```

## 3.5 数据分辨率容错（2026-08-08）

```text
事实：1 分钟存档只有高成交量市场有（BLG G1 143 万 vs Liquid G1 5.3 万 USDC；
  1d/1 对低活跃市场返回空，只能拿 5-10 分钟）。

容错规则：
1. 取数层：tools/fetch_price_snapshot.py 自动回退（1d/1 -> 1m/10 -> max/5），
   README 标注实际分辨率；回测按实际分辨率标注结论（5 分钟回测 != 1 分钟回测）。
2. 触发层：无 1 分钟数据的市场，"单根 +10c"改为"5 分钟 bar 确认（5 分钟拉升 >=15c）"
   或实时中间价突破；禁止把 5 分钟数据当 1 分钟用。
3. 选择层：彩票机器优先选高成交量市场（数据 + 流动性双保障）；
   低成交量市场只做观察，不做触发。
```

## 4. 仓位与风控

```text
层 1 单场全成交成本 $29（彩票池内）；层 2 确认仓 $10-20。
彩票池占总资金 10-20%；单场 + 单日上限遵守 config/risk_limits.json。
同一小局只允许一个方向进入彩票机器（禁止双边买）。
归零是预算内可接受的；成交即挂止盈/止损（交易所级，不依赖脚本进程）。
```

## 5. 人机分工

```text
- 系统：发现 + 机械执行 + 统计（价格 / 流动性 / 时间规则全自动）。
- 用户：比赛阅读作为可选人工信号叠加（假赛感 / 阵容 / 节奏）。
- 先半自动（系统推荐候选 + 用户一键确认 + 系统执行），
  验证后由用户显式开启 autopilot，仅限彩票类小金额。
```
