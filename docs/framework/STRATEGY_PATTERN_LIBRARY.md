# 预测市场网格交易策略模式库

最后更新：2026-08-12

## 1. 定位

这个文件用于沉淀已经可以构建交易策略的市场形态。

更上层的“现象 -> 策略 -> 验证 -> 自动化”分层见：

```text
PHENOMENON_STRATEGY_FRAMEWORK.md
```

核心原则：

```text
不是一次性设计完所有策略。
而是每次交易和复盘后，把高频形态归纳成模式。
模式先进入观察和建议，稳定后再进入自动交易。
```

核心纪律（所有策略共用，第一优先级）：

```text
先止损，再重新进场。
旧仓跌破预设止损线 → 无条件退出，不做"暂时落后还是彻底落后"的盘中判断。
符合新策略模板 → 用新预算 + 彩票仓规模重新进场，成本不继承。
"暂时落后"的机会由重新进场接管，"彻底落后"的仓位由止损兜底。
价格优势线：期望值全部来自"买入价 vs 结算价"的距离——60c 以下买入方向对至少 1.67 倍，
40c = 2.5 倍，20c = 5 倍，5c = 20 倍；高于 60c 的新仓默认小仓或不追。
```

## 2. 策略成熟度

每一种现象和策略都按成熟度推进：

```text
L0 观察模式：
只记录案例，不生成交易建议。

L1 建议模式：
能识别形态，给出买卖建议，但不自动下单。

L2 模拟模式：
用历史价格或纸面交易验证，不实盘。

L3 小额实盘：
允许固定小金额自动执行，强风控，必须复盘。

L4 稳定实盘：
纳入常规自动执行策略。
```

当前成熟度：

```text
S1_REVERSAL_GRID：低价反转网格（S1-深反彩票 / S1-标准中位），旧 A  L3 小额实盘
S2_FAVORITE_DIP_GRID：热门深回撤网格，旧 B                        L3 小额实盘
S3_DOMINANT_PULLBACK_GRID：强势小回撤网格，旧 C   已并入 S2（2026-08-07 决定），保留为历史参考
S4_POSITION_MANAGEMENT：持仓管理，旧 D            L1 建议模式
P5_BO_SERIES_COMEBACK：BO3/BO5 整场反转现象，旧 E L2 回测验证，进入任务 2 发现层
```

分类边界：

```text
P1-P6 是市场现象，回答“发生了什么”。
S1-S4 是交易策略，回答“怎么买、怎么卖、怎么管仓位”。
M1-M7 是执行管理模块，回答“如何挂单、锁盈、控风险、复盘”。
一个候选可以是 P5 + S1，也可以是 P5 + S2，但不应该只有 P5 就进入执行。
```

### 市场层级（先分清，不混用）

```text
小局市场（Game / Map Winner）：单个小局结算（LoL/Dota 的 Game、CS 的 Map）。
  吃局内 20-40 分钟窗口的波动（反转 / 回撤 / 尾盘跳变）；局间不继承。
整场市场（Match / Series Winner · Moneyline）：整个 BO3/BO5 系列结算。
  价格随每个小局进程实时重定价；第三局起无独立小市场只能走 Moneyline；
  吃"系列赛翻盘时间"的折价，是 P5 的专属层。
仓位、止损、复盘按市场分层记账：小局仓不继承到整场，整场仓不按小局处理。
策略总清单（小局/整局分层口径）见 docs/framework/STRATEGY_MASTER_LIST.md。
```

## 3. 当前策略模式

### S1：低价反转网格，旧 A

2026-08-07 定稿：S1 按入场价拆成两档——S1-深反（彩票类）与 S1-标准（中位反转）。
分档原则来自真实案例：入场越低，反弹冲高概率和倍数越高（WE G1 6.5c->100c、WE G2 0.65c->100c、
IG/NIP <5c->79.5c、HLE 12c->100c）；20-50c 中位是 08-05 接刀重灾区，止盈优先锁利。

#### S1-深反（彩票类，均价 <=15c）

适用市场：小局 Game/Map Winner + 整场 Moneyline（通用；Moneyline 版通常由 P5 路由触发）。

典型形态：

```text
盘中/局内跌到 <10-15c（含 5c 以下极值），市场把目标方判死但仍有波动和流动性。
归零在预算内可接受；买入阶梯金额随价格下降递增（份额经济学：低档位买的是倍数）。
```

买入（总彩票预算 $60，均衡权重 1/√价格，越低越多）：

```text
15c:$5.5 / 12c:$6 / 10c:$7 / 8c:$7.5 / 6c:$8.5 / 4c:$10.5 / 2c:$15
七档全成交：总份额约 1405 股，均价约 4.3c。
15c/12c 档决定回本速度，4c/2c 档决定倍数。
```

止盈（卖高留低，按档位归属；sell_cost_basis 为对应档位成本）：

```text
50c 卖 15c/12c 档（成本 $11.5）——回收本金 + 小利
70c 卖 10c/8c 档（成本 $14.5）
85c 卖 6c 档（成本 $8.5）
彩票仓 4c/2c 档（成本 $25.5）吃到 95-100c

快速回本变体（可选）：50c 先卖 15c/12c/10c 三档（成本 $18.5），
回本更快、剩余风险更小，总倍数略降。
```

回测验证（2026-08-07，WE vs AL 1 分钟真实价格，快照 docs/data/snapshots/2026-08-06_lol-we-al/）：

```text
WE G1（低点 6.5c，只成交 15/12/10/8 四档，总成本 $26）：
  先卖 15/12/10 @50c -> 回款 $78.3（投资的 3 倍，回本并锁利 $52），剩余风险 $7.5；
  最终约 5.5-6.1 倍。
WE G2（低点 0.65c，七档全成交，总成本 $60）：
  先卖 15/12/10 @50c -> 回款 $78.3（131% 成本，回本 + 锁利 $18.3），剩余风险 $41.5；
  最终约 20-21 倍。
  对比只卖 15/12 两档：50c 回款 $43.3（仅 72% 成本，未回本），剩余风险 $48.5。
结论：深反类先卖 15/12/10 三档可在 50c 回本并锁利，剩余仓位归零风险显著缩小；
4c/2c 低档留作彩票吃倍数，是份额经济学的正确姿势。
```

新增样本（2026-08-07，小局 G1 极限反转，快照 docs/data/snapshots/2026-08-07_lol-fox1-bro2/）：

```text
BRO G1：1.5c -> 99.95c（10:49-10:51 约 1-2 分钟），深反极值"深跌未必死"的最陡样本；
  另一侧 BFX 98.5c -> 0.05c 同场 1 分钟归零，证明同一局里接刀侧与彩票侧同时存在。
```

D2 深反版：

```text
不硬性在 60/75/80 全锁；动作点改为 70c / 85c：
触 70c 后回撤保护 58c；触 85c 后回撤保护 75c；彩票仓上限 20% 成本。
```

成熟度：设计保留，状态暂缓（2026-08-07 用户决定当前只做中位入场，S1-深反彩票池
后续再启；模板、快照、回测均保留，不做删除）。

彩票机器（环节 4）：2026-08-08 设计定稿 + 反弹确认层历史回测完成，
见 docs/framework/LOTTERY_MACHINE.md 与 reports/lottery_machine_backtest_2026-08-08.md；
主触发定为"单根 +10c（从 <10c 起步）"，待小额实测。

#### S1-标准（中位反转，均价 20-50c）

适用市场：小局 Game/Map Winner + 整场 Moneyline（通用）。

典型形态：

```text
20-50c 中位深跌，未到极端彩票区；本区间是 08-05 接刀九连负的重灾区，
默认保守版：快速回本 + 锁利，彩票仓不超过 15%。
```

买入（总预算 $35）：

```text
40c:$10 / 32c:$10 / 25c:$8 / 20c:$7
```

止盈（按成本分档）：

```text
55c 卖 30% 成本
70c 卖 30% 成本
82c 卖 25% 成本
彩票仓 15% 成本
```

D2 标准版：

```text
60c 回收本金；75c 锁主要利润；85c 只留小彩票仓；
回撤保护：触 75c -> 68c，触 85c -> 75c。
```

边界规则：

```text
跌破 18c 停止按标准档加仓；深反暂缓期间，该价位视为止损评估线（D3）：
价格未到止盈区且跌破成本一半，或比赛进入末段仍未反弹 -> 主动离场，不拖到归零。
```

成熟度：L3 小额实盘（模板更新待 dry-run 验证）。

### S2：热门回撤网格，旧 B

适用市场：小局 Game/Map Winner + 整场 Moneyline（通用；Moneyline 版常由 P5 路由触发）。

典型形态：

```text
赛前热门 >=65%（最好 >=75%）。
热门方赛中从 70-80c 高位回撤到 40-50c。
市场还没有确认热门方彻底失控。
```

2026-08-07 定稿修正：B 的买入时机不是赛前/高位（原 72/68c 配置错误），
而是赛中回撤到 40-50c 时接；止盈相应放宽到 62/75/88 + 10% 彩票。

买入（总预算 $30，赛中回撤位）：

```text
50c:$12 / 45c:$10 / 40c:$8
```

止盈（按成本分档）：

```text
62c 卖 30% 成本
75c 卖 30% 成本
88c 卖 30% 成本
彩票仓 10% 成本
```

D2 B 版：

```text
60c 回收本金；75c 锁主要利润；88c 只留小彩票仓；
回撤保护：触 75c -> 68c，触 88c -> 78c。
```

执行目标：

```text
买热门方回撤。
成交后立刻挂分批止盈。
跌破 35c 后停止按 S2 继续加仓；深反暂缓期间不自动切 S1，
转 D3 止损评估（未反弹到止盈区且跌破成本一半，或末段仍未反弹 -> 主动离场）。
```

成熟度：L3 小额实盘。

### 中位入场统一模式（2026-08-07 定稿，当前主攻）

适用范围：S1-标准（20-50c）、S2（40-50c 热门回撤）、P-早建仓（50-60c）。

```text
操作模式：中位入场（如 30c）-> 60-70c 卖出约 80% 成本对应的份额（回收本金 + 锁利）-> 剩余 20% 成本当彩票。
算例（$100 @ 30c = 333 股）：60c 卖成本 $80（267 股）-> 回款 $160（保底 +60%）；
剩余 67 股到 100c -> 总 $227（+127%）；剩余归零 -> 总 $160（+60%）。
前提：止盈必须预先挂交易所级卖单；若价格不到止盈区且跌破成本一半，按 D3 主动离场。
深反（<15c 入场）暂缓，不使用此模式；后续启用时回到"卖高留低"。
```

止损规则（2026-08-07 确认）：

```text
中位止损：跌破成本一半离场（30c 入场 -> 15c 离场，亏损 50% 封顶）；
配套：比赛末段（最后 5 分钟）仍未反弹 -> 离场。
止损单进场即挂（D3 + D4），决定在事前，不在事中。
```

半自动确认边界（2026-08-07 确认）：

```text
开赛前定下策略后：买入、监控、挂止盈全部自动，无需再确认；挂止盈完全不用确认。
主动平仓仍需用户明确表达（红线），计划内自动止盈/止损除外。
```

单场预算：

```text
默认 <=70 USDC；全仓/超限需在策略确认时显式指定金额并触发风控提示，不做默认。
赛前 50-50 全仓（手动）为高风险行为样本，靠运气，不进入系统默认路径。
```

### S3：强势小回撤网格，旧 C

适用市场：小局 Game/Map Winner + 整场 Moneyline（通用）。
2026-08-07 决定：与 S2 合并为"热门回撤接"（见 STRATEGY_MASTER_LIST.md），本条目保留档位细节。

典型形态：

```text
优势方持续压制。
价格多数时间处于 70-90c。
偶尔因为小事件回撤到 70-78c。
盘口流动性好，spread 不大。
```

潜在执行：

```text
不追 90c 以上。
只接小回撤。
目标是 85-95c 小幅止盈。
金额应小于 S1/S2。
临近终局不新开。
```

主要风险：

```text
看似理财，实际是在终局前追高。
高价区收益空间小，spread 和滑点容易吃掉利润。
突发反转时下跌空间远大于上涨空间。
```

成熟度：L2 实验模板，待小额实盘验证。

当前实验模板：

```text
只在 --allow-experimental 下生成执行计划。
默认每轮金额应小于 S1/S2，但建议不低于 15 USDC，否则容易低于 Polymarket 最小下单数量。
买入：当前价不高于 78c 时接当前价附近；高于 78c 时只挂 78c 和 74c 回撤单。
卖出：15 USDC 以下只挂一档核心止盈；15 USDC 以上再拆 +8c / +15c / 98c。
彩票仓：保留约 10% 成本。
```

已发现执行问题：

```text
2026-08-03 GEN vs HLE Game 2：
- 10 USDC 试单可以成交和挂第一档止盈。
- 但多档止盈会导致后续卖单数量低于最小下单量。
- 修正：C 型小资金只挂一档核心止盈；15 USDC+ 才拆多档。
- 修正：监控重启时会认领已有同价卖单，避免重复挂卖单。
```

升级到 L3 条件：

```text
收集至少 10 个 C 型案例。
验证 70-78c 回撤买入后，是否经常能回到 85c 以上。
统计 spread / 滑点对收益的影响。
完成至少 1-3 次小额真实验证，确认不会追高和重复下单。
```

### S4：已有持仓救援 / 成本管理，旧 D

典型形态：

```text
用户已有仓位。
买入后价格下跌。
用户不想直接止损，希望通过反弹减仓、补仓或彩票仓管理降低风险。
```

潜在执行：

```text
先读取已有仓位和未成交挂单。
先做风险降低，不默认补仓。
如果仍有反弹空间，优先挂减仓单。
只有形态同时符合 S1/S2/S3 时，才考虑小额补仓。
```

主要风险：

```text
用补仓掩盖错误判断。
已有仓位和新策略仓位混在一起，导致重复卖或重复买。
用户想“不要止损”，但市场已经进入终局。
```

成熟度：L1 建议模式。

升级到 L2 条件：

```text
先实现可靠的持仓读取和订单归因。
能区分旧仓、本策略新仓、已有卖单锁定仓位。
完成至少 5 个历史/手工 D 型复盘。
```

## 4. 机会发现标签

### P5_BO_SERIES_COMEBACK：BO3/BO5 整场反转，旧 E

适用市场：整场 Moneyline（BO3/BO5）专属；小局市场不适用。

定位：

```text
P5 不是新的下单策略，而是规律探索层的现象标签。
它专门扫描 BO3 / BO5 的 Match Winner / Series Winner。
识别首局失利、前半段落后、或整场价格被阶段性压低后的修复机会。
最终交易主标签仍然必须落到 A / A2 / B2，后续也可以扩展到新的主策略。
```

为什么重要：

```text
单局 Winner 只能看到当前小局。
Match Winner / Series Winner 会把“首局输了但整场仍能翻”的折价暴露出来。
这类市场经常出现 30c-70c 的修复窗口，适合固定金额网格。
```

第一版识别条件：

```text
市场必须是 Match Winner / Series Winner。
赛制优先 BO3 / BO5。
目标方第一局失利、前半段落后，或价格序列表现出明显折价。
当前仍有系列赛反转时间，不接近终局。
成交量、盘口深度、价格更新时间达标。
```

暂时没有实时赛况时，用价格序列近似：

```text
开盘/早段 >=55c，随后跌到 55c-70c：P5 + P2，路由到 S2。
开盘/早段 >=55c，随后跌到 30c-45c：P5 + P3，先建议/模拟。
开盘/早段 <=35c，随后跌到 5c-30c：P5 + P1，路由到 S1。
```

路由规则：

```text
P5 + P1：5c-30c 低价反转，复用 S1。
P5 + P3：30c-45c 中位反转，第一版只建议/模拟，预算低于标准 S1。
P5 + P2：复用 S2；若跌破 40c，不继续按 S2 加仓。
所有 P5 叠加交易成交后，强制接入 D2 自动锁盈。
```

已沉淀样本：

```text
Dota2 VG vs Yakult Brothers：P5 + P1 -> S1，低价深度反转，$25 回测 ROI +196.4%。
CS2 SPARTA vs ex-Young Ninjas：P5 + P3，中位反转，$25 回测 ROI +34.7%。
LoL NAVI vs Shifters：P5 + P2 -> S2，强队折价修复，$25 回测 ROI +33.5%。
LoL IG vs NIP（2026-08-06）：P5 + P1 -> S1 实时样本。G1 IG 获胜后 NIP 被判死：
Moneyline 最低 <5c（10 分钟采样 6.5c）、G2 Winner 采样最低约 13c；
G2 局内翻盘后约 10 分钟内 Moneyline 拉到 34.5c、G2 Winner 拉到 79.5c。
LoL WE vs AL（2026-08-06 晚间）：P5 + P1 -> S1 conviction 样本（CLOB 1 分钟粒度已核验）。
赛前 WE 约 33-35c（约 40%）；G1 低点 6.5c@13:58、G2 低点 0.65c@15:16；
用户以"假赛感"（领先方送人头）为边际信息买入，均价 13c/20c；两局翻盘兑现（14:29 / 15:22 结算），
WE 2:0，约 +600（口述估值）；快照落盘 docs/data/snapshots/2026-08-06_lol-we-al/。
  ```

## 5. 执行层通用模块

### P：赛前小底仓 / Pre-position

定位：

```text
P 不是独立策略，而是仓位节奏模块。
它可以和 S1/S2/S3/S4 组合使用。
```

典型需求：

```text
用户赛前看好某一方，想先少量买一点。
真正的大仓位留到赛中波动后再做网格。
```

默认规则：

```text
金额小，默认 5-10 USDC。
只在用户明确表达“赛前小买一点 / 小底仓 / 先买一点”时执行。
不自动满仓。
不因为赛前买了就赛中无脑补仓。
赛中继续按 S1/S2/S3/S4 判断是否加仓、减仓或止盈。
```

主要风险：

```text
占用可用余额，导致赛中网格第二档或止盈卖单余额不足。
用户主观强时容易把小底仓变成大仓。
赛前信息少，价格未必有好盈亏比。
```

执行要求：

```text
必须记录为 pre-position。
后续网格交易需要区分赛前底仓和策略新仓。
余额不足时，优先保证已成交仓位的止盈卖单。
```

### P-早建仓：开局/领先确认早建仓

适用市场：小局 Game/Map Winner + 整场 Moneyline（通用）。

定位：

```text
解决"五五开开局 -> 全局领先 -> 没早买就买不到"的场景。
用价格优势换时间优势：信息少时在低价买入场资格，买入后跟随 D2 保护。
```

触发条件：

```text
- 用户或系统有方向判断（主观看好 / P5 标签）。
- 价格仍在价格优势线内：<=60c。
- 比赛早期（领先未确认或刚开始确认）。
```

结构（单场预算的 25-30%，分三档）：

```text
50-55c 买 1/3（开局五五开）
56-60c 买 1/3（领先确认）
40-50c 回撤补 1/3（S2 回撤档）
```

硬规则：

```text
- 高于 60c 不追（守住价格优势线）。
- 买入后立即挂 D2 保护。
- 归入 pre-position 记账，与策略新仓区分。
```

主要风险：

```text
信息少时进场，方向错了同样亏损；仓位必须小（<=30%），且必须配 D2。
```

组合方式（2026-08-07 确认）：

```text
P-早建仓不是独立策略，是与 S1-标准 / S2 组合的执行模块：
1. 开赛前/开局：P-早建仓买入 <= 单场预算 30%（50-60c 分档），拿到入场资格。
2. 赛中接力：价格回撤到 20-50c -> S1-标准接力（低吸 + 买80回收）；
   热门回撤到 40-50c -> S2；一路领先 -> 底仓按 D2 锁盈。
3. 记账：pre-position 与策略新仓分开，止盈统一由 D2 管理。
4. 预算：底仓 + 接力合并 <= 单场预算上限（当前 80）。
5. 止损：底仓方向错同样按"跌破成本一半"离场。
```

### D2：浮盈保护 / 自动锁盈

定位：

```text
D2 不是入场策略，而是所有策略都可以调用的执行保护模块。
```

适用：

```text
低位买入后已经明显浮盈。
价格进入 60c-80c 区间。
剩余仓位仍然较大，不应该被视为彩票仓。
电竞尾盘存在高反转风险。
```

最极端反面样本（2026-08-07）：BFX G1 98.5c -> 0.05c 仅 1 分钟（快照
docs/data/snapshots/2026-08-07_lol-fox1-bro2/）——未在 75-85c 锁盈 80% 的代价是从 +95c 变 0。

默认规则：

```text
60c-65c：回收本金。
70c-75c：锁定主要利润。
78c-82c：只保留小彩票仓。
```

彩票仓上限：

```text
原始成本的 10%-20%
或固定 5-15 USDC
取更小值。
```

产品原则：

```text
系统不是为了赚到最后一分钱，而是为了防止把已经赚到的钱还回去。
```

### D3：止损决策 / 仓位退出状态机

定位：

```text
解决"暂时落后 vs 彻底落后"的止损难题。
核心原则：不要求在盘中判断"是暂时还是彻底"（无法可靠判断），
改为"先按纪律退出，再按新状态决定是否重新进场"。
旧仓退出和重新进场是两个独立决策，成本不继承。
```

止损价值的时效性：

```text
止损的价值在"早"不在"晚"：跌破止损线第一时间离场，保存的是剩余价值
（30c 入场 20c 离场少亏约 67%）；等价格跌到 3-5c，卖与不卖差别确实不大。
所以止损线必须设在还有价值的价位，且进场即挂——不能等到"感觉没意义"再决定。
```

状态机（第一版）：

```text
A 正常持有：价格在止损线上方，按止盈分档退出，不干预。
B 保护带：价格进入止损线与止盈回撤线之间；停止所有新加仓；已有止盈挂单继续；允许部分减仓。
C 触发止损：跌破止损线，无条件关闭旧仓，不做人工判断。
C→重评估（重新进场触发条件，2026-08-08 细化）：
   旧仓退出后，满足以下全部条件才允许重新进场（否则本轮交易结束）：
   1) 形态匹配：新价格状态符合 S1-深反（<10-15c 有波动有流动性）/ S1-标准（20-50c）/
      S2（40-50c 热门回撤）之一，且符合深蹲判别器"快速反弹型"信号
      （低点后首次反弹出现 + 二次探底不破前低）。
   2) 时间剩余：距结算 >= 15 分钟；临近终局禁止。
   3) 流动性：spread 达标、盘口深度足够、价格未长时间停滞。
   4) 彩票仓规模：新仓金额 <= 单场彩票仓上限，且通过当日 D6 回吐检查。
   5) 独立记账：新仓 + 新预算，成本不继承（禁止补仓语义）。
```

为什么这样能解决"暂时落后"：

```text
"暂时落后"的机会没有丢——由"C→重评估"接管；
"彻底落后"的仓位不会拖到归零——由"C 触发止损"兜底。
代价是偶尔被洗出去（卖出后价格又回来），这是保险的成本，
远小于 130 USDC 拖到接近归零的代价。
```

自动化可用的辅助信号（提高重评估准确率，不改变决策方式）：

```text
时间：距离结算越近，"落后还能翻"的先验越低；临近终局禁止 C→重评估。
轨迹：慢磨阴跌 vs 快速跳变；是否有反弹尝试及其力度。
流动性：盘口深度、持续成交、价格更新时间。
模板匹配：与 S1/S2/S3 形态参数匹配才允许重进。
```

止损线预设（第一版）：

```text
S3 强势方：0.60 止损。
S2 热门方：0.40 以下停止按 S2 加仓，评估切 S1。
S1 深反：买入即视为彩票仓，止损 = 归零预算，不追加。
所有买入成交时同时挂止损单。
```

主要风险：

```text
把"重新进场"误当作"补仓"，变相拖住旧仓。
→ 强制要求：新仓独立记账、新预算、新彩票仓上限，禁止用旧仓成本补单。
```

成熟度：L1 建议模式，纳入工具升级关键项。

### D4：进场三件套 / 先挂单后买入

定位：

```text
把"止盈、止损、彩票仓上限"变成买入的前置条件，而不是盘中决定。
```

规则：

```text
买入成交前必须已挂好：
1) 止盈分档（按策略模板，如 0.84 / 0.91 / 0.98）；
2) 止损线（按 D3 阈值）；
3) 彩票仓上限（原始成本 10%-20%）。
未挂齐 → 不允许开仓；系统校验，人工下单也按同一套校验执行。
```

工具升级项：

```text
trade_config.schema.json 增加必填字段：take_profit_ladder / stop_loss / lottery_cap。
下单流程校验"卖出计划先于买入"，不满足则拒绝生成计划。
```

成熟度：L1 建议模式。

### D5：信心溢价仓位规则

定位：

```text
防止"感觉稳"变成重仓理由。
定义：信心溢价单 = 没有边际信息、只因主观看好而买入（例：近五五开市场买 T1）。
```

规则：

```text
信心溢价单按彩票仓对待：金额 ≤ 单笔预算 10%-20%，可归零，不设目标利润。
正常网格仓位只允许给有形态/信息支撑的单（S1/S2/S3/P5 模板匹配）。
仓位与信心溢价成反比：越接近"纯感觉"，仓位越小。
```

成熟度：L1 建议模式。

### D6：每日回吐上限

定位：

```text
打断"白天全赚 → 单笔重仓吐光 → 靠运气回血"的循环。
```

规则（第一版）：

```text
每日开盘前设定当日最大可回吐：已实现盈利的 30% 或固定 50 USDC，取更小值。
达到上限 → 当日停止所有新开仓，仅允许已挂止盈单执行。
```

成熟度：L1 建议模式。

## 7. 自动化原则

```text
所有策略最终都可以自动化，但不能同一天从想法跳到实盘。
S1/S2 当前允许小额实盘。
C 当前允许在明确实验开关和人工确认后生成小额试单计划。
D 和未来新策略先进入建议和复盘。
通过模拟和小额验证后，再进入自动执行。
```

自动化不是为了更激进，而是为了更稳定：

```text
不情绪化补仓。
不忘记挂止盈。
不硬扛"暂时落后"的仓位——先退出，符合新策略再重新进场。
不重复下单。
不把关闭订单和平仓混淆。
不在终局阶段追高。
```

## 10. 执行模板（按比赛类型路由）

### 模板 A：赛前高信心局

适用：用户赛前明确看好、赢面判断强。

```text
赛前仓占比：事件预算的 40-50%（上限，不再重仓；大部分子弹留给赛中低吸）。
低吸：只放极端低位 10-25c，金额小（避免接飞刀）。
止盈：移动止盈或高梯队（回撤才走）；第一波止盈后不追高。
彩票仓：保留 15-20% 到结算。
```

反面教训（2026-08-04 BRO vs DRX 第三局）：

```text
五错叠加，赢局变亏：
1. 赛前仓只有 40/97（42%），子弹留到比赛中。
2. 低吸放在 42-48c 波动中段，一路接飞刀（最严重错误）。
3. 冲高 79/80c 追买加仓，成本越抬越高。
4. 第一波 52/60/68c 止盈太早，吃到确定利润但丢了大肉。
5. 急跌 34c 市价割肉 150 股，割在最低点。
结论：高信心局赛前仓最多 40-50%（不重仓），剩余子弹留给赛中低吸；
低吸放极端低位 + 移动止盈 + 不追高 + 不市价割。
2026-08-05 追加：昨日尾盘多笔亏损（BRO 决赛、YB G2、ES1 G2）后，
明确「不赛前重仓」——所有模板赛前仓一律不超过 50%。
```

### 模板 B：标准策略 A/B 局

适用：普通「看好」的默认执行（用户表达看好但未到高信心）。

```text
赛前仓：事件预算的 1/3。
低吸：A 型 20-30c 档；B 型热门回撤档（现价下方 3-5c 起）。
止盈：分档止盈覆盖 80%，彩票仓 20%。
不追高、不市价割；急跌用挂单分批处理。
```

注意：这是策略 A/B 的标准打法——「看好」默认 = 赛前少量买入一部分 + 比赛开始后挂单低吸补仓；
赛前重仓只保留给用户明确表达「信心非常足」的高信心局（模板 A）。

### 模板 C：小仓试局

适用：轻微看好、试水性质。

```text
总量：25-35 USDC。
市价小仓 + 1-2 档低吸。
止盈放高（90c+），拿久一点。
```

### 模板选择规则

```text
用户表达信心级别路由：
「看好」但未到高信心 → 模板 B（赛前少量 1/3 + 赛中挂单低吸）——默认执行
明确「信心非常足 / 赢面非常大」→ 模板 A（赛前仓最多 40-50%，不重仓）
微微看好 / 少量试水 → 模板 C
关键：普通「看好」≠ 赛前重仓；即使高信心，赛前仓也不超过 50%。
下单前先确认模板类型，再按对应纪律执行。
```

### 执行模式：滚动降成本 + 分段锁利（2026-08-05 确认）

适用：对同一市场持中期仓位、判断会有波动时。

```text
动作：高价区间（如 +8~20c）分批挂卖单锁利；深跌区间（如 18-30c）分批挂低吸买单。
效果：卖出的份额由低吸接回，总体仓位基本不变，但均价被拉低，过程中利润分批落袋。
案例：
- 2026-08-04 T1a G2：均价 71.6c → 高位卖、低位接 → 53.1c。
- 2026-08-05 NS 整场：226.5 股 @ 46.6c + 70/75/80c 卖单 + 18/24/30c 低吸。
纪律：
- 卖出档永远高于当前成本；低吸档只在深跌区（不接飞刀）。
- 每次循环后重新核对仓位与均价，确认「仓位不变、成本更低、利润已锁」三要素。
```

### BO3/BO5 第三局没有独立 Winner 小市场，走 Moneyline

规律：

```text
BO3/BO5 系列赛中，Game 1 / Game 2 通常有独立的 Game Winner 小市场。
但从第三局开始不再单独开 Winner 市场，第三局输赢直接体现在整场 Moneyline（Match Winner / 系列胜者）市场里。
```

真实案例（2026-08-04）：

```text
Gen.G Global Academy vs Hanwha Life Esports Challengers（LCK Challengers 试训小组 BO3）。
第二局结束后系列赛 1-1，第三局没有 Game 3 Winner 子市场，
只有 lol-genga-hle-2026-08-04 整场胜者市场，HLE 定价约 68.5c。
```

执行含义：

```text
想在第三局买入某队 → 直接在整场 Moneyline 市场挂单，不要等一个不存在的 Game 3 市场。
想等第三局低点加仓 → 在整场市场现价下方挂低吸单，策略 B（热门回撤）逻辑同样适用。
第三局结果不单独结算，整场市场随系列赛进程实时重定价。
```

检查方法：

```text
在 gamma 事件 markets 里找不到 "Game 3 Winner" 子市场时，
确认第三局走 Moneyline（整场胜者）市场，避免空等独立市场开放。
```
