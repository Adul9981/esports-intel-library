# 策略总清单（小局 / 整局分层）

最后更新：2026-08-08

用途：策略的总目录。每次新发现或复盘结论先挂到对应条目下；**小局与整局策略分开，不混用**。
细节与档位以 `docs/framework/STRATEGY_PATTERN_LIBRARY.md` 与 `config/strategy_templates.json` 为准。

## 0.5 颜色定位（三档，2026-08-08 定）

```text
🟢 绿 = 正期望 + 已实盘多次验证 + 可半自动   -> 常规做（主攻）
🟡 黄 = 逻辑/回测成立，但实盘样本不足或需严格纪律 -> 谨慎做（小仓验证）
🔴 红 = 负期望（规则性不做）或完全未验证/暂缓    -> 不做，或先回测/小额试点（彩票池）
```

注：颜色是"操作姿态"，不是判断对错；红 ≠ 永久禁止，绿也需要遵守仓位与保护纪律。

刷新规则（2026-08-08）：策略颜色/仓位档位**每累计 10 笔真实交易或每周刷新一次**，
不每次交易后刷新；刷新时用真实样本统计（胜率 / 平均盈亏 / 期望）更新，回测只作参考。

赛前预期价（TODO，2026-08-08）：当前只有盘中价格分析，缺少"赛前预期价 vs 开盘价"的价差检测
（P-早建仓的前提）；归属执行层（半自动决策输入），待建立。

## 0. 两个市场层级（先分清）

| | 小局比赛（Game / Map Winner） | 整局比赛（Match / Series Winner · Moneyline） |
| --- | --- | --- |
| 结算对象 | 单个小局：LoL/Dota 的 Game 1/2/3、CS 的 Map 1/2/3 | 整个 BO3/BO5 系列的胜者 |
| 结算时点 | 小局结束立即结算（0 / 100） | 系列赛结束才结算，中途不结算 |
| 价格驱动 | 单局内团战 / 回合 / 资源事件 | 每个小局进程实时重定价（G1 结果、G2 结果、决胜局…） |
| 翻盘时间 | 局内波动窗口（约 20-40 分钟） | 系列赛翻盘窗口（还有几局可打） |
| 市场结构 | BO1/BO3/BO5 的 G1、G2 有独立 Winner 市场 | BO3/BO5 专属；**第三局起无独立小市场，只能走 Moneyline** |
| 常见陷阱 | 把局内接刀当成深反（WE vs TT G1 10-15c 接刀） | G1 被翻后把 Moneyline 留仓赌 G2（BFX 死亡螺旋 75.5c -> 0.05c） |

原则：仓位、止损、复盘都按市场分层记账——小局仓不继承到整场，整场仓不按小局处理。
分类按"实证来源 + 交易主战场"优先：**小局第一、整局第二、通用/特殊收尾**。
实证（2026-08-08 T1 vs HLE）：买"G2 单局"输局即归零；买"Moneyline 整场"输一局只回撤、
决胜局仍有翻盘机会（G3 翻盘则 +39%）——单局 vs 整局的结构差异是分层的核心依据。
形态气候规则（2026-08-08）：反转日（A 类高频）低错杀位买、高位不追（90c+ 死亡区）、
连续 2 笔亏损强制减半、D6 到线只看不开；反转日最常见的错误是领先被翻后连续加注翻本。

## 4.5 策略资金分层（稳定池 vs 高赔率池，2026-08-10 定）

```text
两种策略角色，资金与仓位分开管理（与颜色正交：颜色 = 操作姿态，池 = 资金维度）。

稳定池（长期盈利，常规仓位，占总资金 70-80%）：
  S2 热门回撤、S1-标准中位反转、大热门躺赢（画像/状态确认）、
  P5 系列赛翻盘（先验支撑）、信号加仓（阿卡丽单杀类）

高赔率池（小资金博弈高赔率，可归零，占总资金 10-20%，单笔小仓）：
  S1-深反彩票、彩票机器、强强对话错杀（A7）、CS 深水区反转
  （K27 整场 6c->100c 16 倍 / Map2 11c->100c 9 倍，08-09）、事件型小注（一血类）

高赔率池纪律：
  - 归零预算内、单笔上限；不因一次 16 倍放大仓位（FNC/K27 教训）。
  - 等"深水区反转启动确认"（单局上穿 0.3/0.5）再进，不接最低点。
  - 稳定池亏损日不挪用高赔率池翻本；D6 回吐到线整体停。
```

## 5. 不算策略的（执行模块）

```text
D2 锁盈（尾盘崩塌 / 尾盘极限反转保护 = D2 的应用场景）
D3 止损状态机 / D4 进场三件套 / D5 信心溢价仓位 / D6 每日回吐
D-EDGE 边际信息登记（情报层输入：只做方向过滤与仓位上限依据，后台统计不上前台，见 knowledge/EDGE_LOG.md）
滚动降成本（持仓动作，不是策略）
D-CHECK 信息自检（2026-08-09）：下单前问"这笔单和我的第一判断一致吗？"——不一致不下；
  群聊/二手观点必须用市场验证（赔率方向与观点一致才信），否则当噪音（BFX/DRX 群聊带偏案例）。
让分盘一律按归零预算（-1.5 / +1.5 都可能横扫归零，74.5c 不是固收）。
G1 输后强队按联赛先验：LCK 12.5% 别抢反弹（彩票预算小仓）/ LPL 42.9% / LEC G2 赢回 83% 可小仓。
全仓赢不改变全仓风险（DNS G3 全仓赢是运气修正不是方法修正）；逐笔加仓时现价高于成本即停（DRXC G2 70c 加到 300+ 反面）。
```
