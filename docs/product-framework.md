# 电竞交易情报平台框架（任务 6 · 高优先级）

最后更新：2026-08-11

最高原则（2026-08-11 用户确认，适用于整个情报库）：**网站清清爽爽提供情报分析**。

```text
界面清爽：一屏一件事、留白充足、不做装饰；信息只保留"有用且可溯源"的。
分析干净：只给事实与统计，不给买卖建议；每条情报能回答"所以呢"，否则不展示。
状态透明：无样本显示"样本不足"，无信号显示"今日无信号"，陈旧结论自动降级。
免责底线：页面固定注明"仅提供历史统计与情报分析，不构成任何投资建议"。
```

## 0. 核心大功能（一页看懂，2026-08-18）

```text
定位：历史档案库 -> 今日辅助决策。只给事实与统计，不给买卖建议。

三大核心功能：
1. 今日比赛：机会卡（信号 + 同形态统计 + 双方档案速览 + 风险）+ 形态气候（昨日定稿 + 今日滚动）。

3. 比赛档案 / 情报库：四维查询（联赛 / 队伍 / 形态 / 策略）+ 反转统计视图 +

数据底座：Polymarket 行情 + 1 分钟快照（187 序列 / 49 组）+ 形态黄金样本 156 +
弹幕情报（4165 条）+ 解说信号 + 复盘知识库。
第二期：触发式预警、策略实验室、导出 / API。
```

## 1. 平台是什么

```text
平台 = 实时情报台（今天在发生什么）+ 历史档案库（过去沉淀了什么）。
历史档案是实时决策的底库：今天敢不敢看，靠的是历史上这支队伍领先稳不稳、落后能不能翻。
```

## 2. 板块一：实时情报台（今天）

每场比赛一张情报卡，五类情报：

| 情报 | 内容 | 回答什么问题 |
| --- | --- | --- |
| 盘口 | 现价、走势、深度 / spread、机会分 | 现在是什么情况 |
| 现象 | P1–P6 标签 + 同形态历史统计（出现次数、反转成功率） | 历史上这类形态怎么收场 |
| 队伍 · 翻盘画像 | 被翻盘率、翻盘率、领先稳定性、落后反弹力（来自历史档案库） | 领先 / 落后可不可信 |
| 队伍 · 近期状态 | 连胜 / 连败趋势；连续低迷的队伍暂时领先时，标记"被反弹风险" | 领先还守得住吗 |
| 事件 | 内讧、人员更换、教练 / 赛程变动；人工 + 半自动录入（可从聊天记录 / 公开资讯沉淀），标注来源与时效 | 赛前预警、机会或风险 |

外加风险提示：假赛风险观察（LPL 高发，只给信号 + 依据，不给结论）、终局风险、流动性不足。

平台只给情报与统计，不给交易建议：说"发生过多少次反转、反转可能性多大"，不说"建议买"。策略路由只存在于内部交易系统，不对外展示。

### 机会卡片规则（"今天有什么机会"）

```text
值得看判定：命中形态 / 现象信号，或队伍画像 / 事件信号，且可成交性达标；
低活跃市场自动降级为"仅观察"，不进机会卡。
卡片内容（5 块，紧凑）：
  1. 对阵 + 比赛时间 / 状态（小局 / 整场）
  2. 信号标签（形态 / 现象，最多 2 个）+ 同形态历史统计一句话（出现次数、反转成功率）
  3. 双方档案速览（两队风格 / 近期走势 / 被翻盘情况）
  4. 风险提示一个（终局 / 流动性 / 假赛观察，取最要紧的）
  5. 详情入口
排序：进行中 > 即将开始；双信号（形态 + 画像 / 事件）优先于单信号。
数量：每天最多 8 张，其余进"全部赛事"。
原则：每张卡片只回答三个问题——这场有什么信号？历史上同类怎么收场？最大风险是什么？
不出现任何"建议买"字样。
```

### 赛前档案卡（档案库 → 今日辅助决策）

今天有比赛时，先出一张"历史档案卡"（示例见 docs/task/v1_framework_preview.html · 赛前档案卡页签）：

```text
1. 近期赛果与比分：最近 5 场左右，赢 / 输、几比几。
2. 碾压情况：全程压制场次占比（无回撤 = 低交易价值）。
3. 盘口价格走势特征：深反 / 崩塌 / 压制 / 震荡，低点与反弹幅度。
4. 情况梳理：2-3 条中性关注点（如"该队有整场领先崩盘先例"）。
5. 类型占比：形态 / 现象标签分布（A / B / C 家族占比）。
6. 小局 vs 整场：Game Winner 与 Moneyline 分别统计。
定位：内容泛而真实、有数据支撑；只给背景与统计，不给买卖判断。
```

### 分析内容三层（分析沉淀 → 档案库）

```text
策略分析：S1 / S2 / 中位80 / 让一追二 / 四阶段窗口（策略场景历史统计）。
图形分析：A / B / C 形态库 + 深蹲判别器 + 形态气候（图形频率与基准率）。
分阶段分析：0-10 / 10-20 / 20-30 / 30+ 分钟窗口特征与决策含义（统计口径）。
历史数据回测策略开发由朋友数据集补充（接入中）。
```

## 3. 板块二：历史档案库（过去）

用户进入后能直接看到的历史数据，核心是《英雄联盟》等赛事的：

```text
队伍战绩：赢了多少场、输了多少场（按联赛 / 赛季 / 对手强度分层）。
翻盘画像：翻盘率（落后时赢下的比例）、被翻盘率（领先时输掉的比例）、领先稳定性、落后反弹力。
历史对局：每场价格走势、现象标签、策略路由、结算结果。
复盘案例：回测与真实交易的结论与教训（knowledge/reviews 现有沉淀）。
口径：小局（Game Winner）与整场（Match Winner）双口径都展示、都算，两个都有独立统计与价值。
```

数据分级（决定档案库能多快上线）：

```text
已有：本地 41 组快照 / 167 条序列 + 回测 + 复盘，先用来验证档案库口径。
朋友历史数据：朋友已在抓取历史数据，接入后回填队伍战绩与翻盘画像（批量数据源）。
需持续积累：盘中价格序列（1 分钟流）-> 翻盘率样本随时间增长。
```

### 档案库查询能力（数据库）

档案库是一个可查询数据库，用户按维度组合查询：

```text
按比赛：赛事名、日期、BO 类型、小局 / 整场。
按联赛：LPL / LCK / LEC / CS2 / Dota2、赛季。
按战队：任一方队伍、对手组合。
按现象：P1-P6（如 P5+P1 低价深反）。
按画像：翻盘成功 / 被翻盘、翻盘率与被翻盘率区间。
按事件与风险：内讧、换人、假赛风险观察。
（可选）按主观信号：957 / 毛毛 / 记得 / 米勒说过"要翻"的比赛。
查询结果 = 比赛列表（每场带摘要），点击进入比赛档案 / 比赛情况。
```

## 4. 情报库功能补充：翻盘案例数据模式（三阶段）

在情报库中建立统一的数据模式：每个"翻盘事件"记成一条结构化案例，按三个阶段描述，每个字段标明来源（客观 / 主观）与可信度。

### 阶段一：翻盘前（市场怎么看死它）

```text
客观（盘口）：
  价格区间与最低点（低点价格、时间、跌速）。
  波动特征（穿越 50% 次数、单根幅度、纠缠指数）。
  盘口质量（深度、spread、成交量）。
  市场上下文（BO 当前比分、局内阶段、剩余时间 / 终局风险）。
主观（参考）：
  解说参考（时间、解说者、原话摘录、观点方向）。
  状态线索（连败、内讧、人员更换、手感）。
  传闻与观察（来源 + 置信度）。
```

### 阶段二：翻盘中（反转怎么发生的）

```text
客观（盘口）：
  触发点（低点后单根拉升幅度与时间，如 1 分钟内 8c -> 20c）。
  价格路径（反弹曲线、是否穿越 50%、是否回踩）。
  盘口反应（深度、spread、成交、买卖盘方向）。
  现象标签（P5+P1 / P5+P2）。
主观（参考）：
  解说转折信号（"这波要翻" / "状态回来了"）。
  局内事件（待外部比赛数据：击杀、资源、阵容）。
```

### 阶段三：翻盘后（怎么收场的）

```text
客观（盘口）：
  结算结果（100c / 0c）、反弹峰值与到达时间。
  止盈窗口（适合分批卖出的价格区间）。
  是否持续到终局。
主观（参考）：
  赛后定性（解说复盘、我们的复盘结论）。
```

### 客观 / 主观数据分层

```text
客观：Polymarket 行情（现有）+ 外部电竞比赛数据（待获取：局内事件、比分、阵容）。
主观：虎牙解说信号、直播弹幕、朋友聊天记录、用户观察；一律标注"主观"、来源与置信度，与盘口交叉验证。
```

### 虎牙解说信号（主观参考层）

```text
固定解说名单：957、毛毛、记得、米勒（经典英雄联盟解说）。
直播 / 录播 -> 语音转文字 / 人工标注 -> 结构化信号：
时间、解说者、比赛、队伍、观点方向、置信度、原话摘录。
只做参考引用并标注"主观"，摘录而非全文，注意引用边界。
```

### 示例：WE vs AL G2（2026-08-06，真实数据）

```text
翻盘前：低点 0.65c @ 15:16（1 分钟粒度），此前从 33.5c 一路下跌，市场判死。
翻盘中：单根拉升 >=10-15c 触发反弹确认；约 10 分钟拉到 79.5c 级别；现象标签 P5+P1。
翻盘后：最终 100c 结算；止盈窗口 50/70/85；用户 13c 上车约 7 倍。
主观：用户"假赛感"（领先方 AL 送人头）记为 conviction 样本，标注主观。
```

## 4.5 情报库功能点（形态 / 策略成果对照，六点全部落地）

> 注：4.5-4.8 为功能点候选库（背景清单），不代表 V1 全部兑现；V1 兑现范围以 5.2 版本分层为准。

```text
1. 形态频率与形态气候（重点功能）：
   - 每场自动打形态标签（tools/classify_pattern.py 启发式 v1.2 已有，全库未知仅 3）。
   - "今日形态气候"：按日统计反转类 vs 崩塌类占比（如 08-07：B1 崩塌 x4、A1 深反 x3、B2 死亡螺旋 x2）。
   - 形态气候标签：反转日 / 崩塌日 / 混合日，作为当日风险提示（崩塌日：领先方锁盈风险升高；反转日：深反样本增多）。
   - 展示形态（2026-08-11）：昨日定稿 + 今日滚动双显——昨日为完整统计基线；
     今日每场结算后自动补标签、标注"进行中 x/y 场"；盘中形态为临时标签、可能修正，最终以结算为准。
   - 情报卡"现象"处给同形态历史统计：出现次数、反弹到 50 / 70 / 100c 概率
     （现有基准：28 个市场侧样本，深跌后反弹 43% / 43% / 38%）。
2. 双边形态刻画：档案卡同时展示赢家侧 / 输家侧形态（A1 深反常与 B1 崩塌同场互证）；复盘模板已并入。
3. 赛前情报层（重点功能）：
   - "预期情形"区块（假说层）：BP / 阵容、队伍状态、赛程密度、队伍画像
     （TEAM_PROFILES 已结构化：队伍 / 风格 / 形态倾向 / 证据 / 信任）。
   - 队伍画像 x 形态倾向进入档案库查询维度（如 BLG 大优易 B1 崩塌、TES 低位反转执行者）。
   - 护栏：预期情形 = 假说，只能定方向偏好与仓位上限；放大仓位必须等盘中形态确认。
4. 可成交性赛前参考：成交量 / 盘口深度 / spread / 滑点预算 -> 每场"可交易性评分"，
   赛前过滤数据与执行双重打折的低活跃市场（参数见 config/risk_limits.json market_filters）。
5. 未知形态通道：未匹配 -> "未知形态"观察池 -> 累计 >=3 个相似图形 -> 登记 -> 回测 -> 入形态库；
   情报库支持按"未知形态"筛选观察池。
6. 止损后重新进场条件（内部机制，不对外给建议）：D3 五条触发
   （形态匹配 + 深蹲判别器 + 距结算 >=15 分钟 + 流动性达标 + 彩票仓 / D6 + 独立记账），
   不满足即本轮结束；对外只展示形态标签与深蹲判别器描述。
7. 结算历史回填（联赛级翻盘率，2026-08-08 登记）：
   - Polymarket 已结算历史市场自动回填队伍战绩 / 翻盘率 / 被翻盘率；
   - 先做联赛级（LCK vs LPL vs CS2 EWC），再降队伍级（样本 >=10 才出画像）；
   - 依赖网络批量抓取，是任务 6 历史档案库的核心数据源。
8. 边际信息登记（EDGE LOG，2026-08-08 登记）：
   - 后台统计"有信息差 vs 纯信心"的胜率 / 期望（knowledge/EDGE_LOG.md）；
   - 统计脚本已建（tools/edge_stats.py，读 knowledge/edges.json；当前 n=6 仅登记，
     结论需每组 >=15-20 条自动累计）；
   - 前台只展示结论（如"该队近期事件敏感 / 假赛风险观察"），不裸展示逐笔明细；
   - 输出到 D5 仓位上限与方向过滤决策。
9. 预期情形盘中验证闭环（2026-08-08 登记）：
   - 赛前假说（TEAM_PROFILES 画像 / 预期情形）-> 盘中可观测信号确认/否定
     -> 行动（仓位上限 / 路由 / 锁盈优先级）；
   - 预期落空记录回画像库，信任等级自校正（knowledge/EXPECTATION_VERIFICATION.md）。
术语统一：下狗 = 赛前低赔率方；落后侧 / 下盘 = 盘中暂时落后方。
```

统计层后台化（2026-08-08 确认）：形态频率 / 形态期望值矩阵 / EDGE 分组统计均为
**内部后台统计**，前台只展示结论性情报（今日形态气候标签、队伍画像、翻盘率、风险提示）；

## 4.6 情报维度补充（2026-08-08 已确认，七项全部采纳）

```text
1. 同场多市场联动 / 背离：G1 / G2 / Moneyline 价格联动；
   "G1 失利但 Moneyline 跌幅小"= 系列赛仍被看好（P5 整场反转的早期信号）。
2. 终局时间衰减：距结算剩余时间 x 历史反弹 / 崩盘率（如 90c+ 后 5 分钟内历史归零率），
   把"终局风险"从定性提示变成量化曲线。
3. 对手强度加权画像：战绩 / 翻盘率按对手强度加权（击败强队权重更高）+ 两队近期交锋记录。
4. 大单与主动成交方向：订单簿失衡 / 主动成交方向统计，作为中立的市场情绪指标。
5. 陷阱 / 反面样本检索：形态的典型死法（B3 假反弹、接刀归零案例），与形态气候互补。
6. 数据可信度层：样本量、时间窗口、数据源、更新延迟、数据健康度（对外可信度 + 内部运维）。
7. 触发式预警：形态触发（A1 确认 / B1 锁定）、画像预警（关注队伍出现被反弹风险）、
   解说信号预警、关注的队伍 / 联赛推送。
```

## 4.7 情报库功能点：解说/主播情报信号（采集与验证闭环，2026-08-08）

```text
- 采集：二路解说/官方解说关键信息（英雄熟练度、阵容克制、选手状态、BP 意外）
  -> 结构化信号（对象队伍/选手、方向含义、可信度、采集时间），库 knowledge/INTEL_SIGNALS.md。
```
