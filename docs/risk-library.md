# 假赛疑似案例库（Match-Fixing Suspect Cases）

> 定位：把"赔率异常 + 比赛行为异常 + 解说提示"的可观察组合记录为**疑似**案例，供后续核查。
> 原则：**假赛无法从赔率/比赛内容证实**；任何"100%"结论必须由外部证据（复盘数据、后续表现、官方调查）支持，否则只记为疑似。

## 案例 1：GIANTX vs Team Vitality（2026-08-14，LEC）

```text
状态：高度疑似（用户判断 100%，未获外部证据证实）
赔率证据：G2 VIT 领先约 1 万经济时 94c -> 0.1c（25 分钟崩盘）；整场 98c -> 60.8c
行为证据（用户观察 + 解说提示）：
  上单 Naak Nako：领先 1 万经济不打团，一味带线
  ADC Carzzy：经济领先非常多，但出装全为加血量（肉装），无爆发性输出
  MID FIESTA：后期无太大作用（注意：夏季赛 VIT 中单为 FIESTA，非 Humanoid；
    Humanoid 2026-06-21/22 被下放不活跃名单，FIESTA 06-29 顶替）
  打野 Lyncas（G3 补充）：解说明确"对面都没有 ADC"时仍出布甲靴（防装靴子），
    装备逻辑奇怪——怪装备信号已覆盖 VIT 除辅助外四个位置（上/中/射/野）
  解说：反复提示"可能是假赛"
终局（G3）：VIT 2:1 赢下整场。G3 VIT 50c -> 100c 正常赢下，
  "演"未在 G3 复现；用户 G3 反手买 GIANTX 全亏（G2 疑似 -> G3 反手 = 过度外推案例）。
已知背景（2026 夏季赛阵容）：Naak Nako / Lyncas / FIESTA / Carzzy / Fleshy
  上单 Naak Nako：2026 春季常规赛 MVP（LEC 史上第二位上单 MVP，carry 型打法，
    "不打团带线"与历史风格矛盾——三者中异常权重最高）
  MID FIESTA：韩国次级联赛出身（BNK FEARX Youth / LCK CL 两次下半区），
    首秀挣扎、Week 3 回勇；"后期无作用"部分可能为实力差距
  ADC Carzzy：老将、输出型 ADC（历史伤害占比 28.2% > 金占比 23.7%），
    "全肉装"极不寻常——但意图无法从单场确认

核查清单（后续逐项打勾）：
1. 复盘数据：G2 伤害构成 / Carzzy 出装时间点 / G3 Lyncas 布甲靴出装时间点 /
   团战参与率（上单带线占比）
2. 后续比赛：Naak Nako / FIESTA / Carzzy 接下来 3-5 场表现是否持续异常
3. 官方/选手回应：是否有声明（LEC 联盟、俱乐部、选手）
4. 盘口异动：同一时段其他平台/市场是否有异常（早于/同步于崩盘的大额单）
5. 该队近期交手：VIT 是否近期多次出现"领先不打"型崩盘
6. 终局回填：G3 结果与整场结算（截至 08-15 凌晨仍未结算，G3 进行中）

结论：待核查。未证实前按"疑似"处理，交易上遇到同类信号先锁盈/减仓。
```

## 案例 1 补充：用户主观判断与弹幕共识（2026-08-15）

```text
用户最新表述（口述）："也许假赛发生了，也许一切都是演的，我觉得演的成分非常大，
  这是我的主观感受。而且观众弹幕之间其实是可以形成一定共识的，共识是有一定解释力的。"
补充（2026-08-15 复盘后）：用户再次明确——"第二局是确确实实的假赛"，
  即用户对 G2 的判断是事实认定（100%），不是猜测。
处理：
1. "演的成分非常大"记录为用户主观感受，不升级为事实结论；
   仍无公开调查/声明/选手回应支持（见核查清单）。
2. "弹幕/观众共识"登记为情报信号源（软信号，可观察、可追溯），
   但明确其用途边界：用于警示与减仓参考，不作为反手/方向依据
   （本场 G3 反手 = 反例：共识出现但 VIT 正常赢下）。
3. 内部记录的表述差异说明（为什么记"高度疑似"而不是"确凿"）：
   - 可证实部分（事实层）：G2 行为组合客观异常（领先 1 万经济不打团、
     ADC 肉装、解说反复提示），赔率 94c->0.1c 极端崩盘——这些都真实发生；
   - 待证实部分（定性层）：是否构成"假赛"需外部证据（官方调查、
     选手/俱乐部回应、盘口异动佐证），目前公开渠道无此类证据；
   - 记录口径不影响交易执行：无论定性为"确凿"还是"高度疑似"，
     同类的处理动作都是"高位先锁盈/减仓、不追高、不反手"。
```

## 假赛疑似通用信号（可观察组合）

```text
1. 领先方突然改变打法：不打团 / 一味带线 / 放弃资源
2. 关键位置怪出装：ADC 肉装无输出、中单后期无用（与选手历史风格矛盾）
3. 解说反复提示"假赛/明眼"
4. 赔率怪异崩盘：高位 80c+ 领先时快速归零
5. 系列赛结构：第一局碾压 -> 第二局"完全不打"
处理规则：命中 >=2 条时，高位仓位先锁盈/减仓，不赌翻倍；记录样本待核查。
```

## 案例 2：T1 vs DN SOOPers G2（2026-08-17，KeSPA Cup 半决赛 BO5）

```text
状态：疑似（社区讨论强烈，无外部证据证实）
背景：T1 上二队（CK 联赛第一），G1 T1 二队碾压赢下；G2 双方拉锯，
  18:30 T1 冲高 76.5c、18:36-18:39 峰值 78c（DNS 深水 21.5c）。
赔率证据：T1 78c（18:39）-> 暂停期阴跌 68.5-71c（18:51-19:12）
  -> 19:15 重启瞬间 35.5c（-33c）-> 19:33 0.5c（3 分钟归零）
  DNS 侧：21.5c（18:39 深水）-> 99.5c（19:33）
事件证据（Polymarket 评论区，series league-of-legends 已抓原文）：
  1. 18:34 起连续多次暂停："technical issue?" / "More pauses to go!" /
     "could have hosted this in my garage with less pauses"（社区多人在线抱怨）
  2. 评论区多人提到 chronobreak/回滚："T1 cheats getting their glitch miracle
     reversed"（18:58）、"sell your overvalued T1 shares ... after chronobreak"
     （19:00，暗示比赛时间回滚将抹掉 T1 优势）
  3. 暂停期大量讨论"比赛取消/暂停如何结算 50-50"（Toxa 引用结算条款、
     LOL-eric "如果不打了是不是就 50 50 分了？"）——规则不确定性直接压价
  4. 19:21 EurekaWTI 直接评论 "match fixing"；19:37 "It does not get
     shadier than this"
  5. 暂停期间网站/下单延迟："website terribly slow"（19:41）、
     "only able to place a sell order on the fifth try"（19:44）——
     暂停期流动性/可用性受损，高位持仓难以退出
用户口述：虎牙直播间弹幕也有相关讨论（待提供房间/录播链接回填）。
与案例 1 的差异：本场无"领先方不打团/怪出装"类行为证据，
  核心是"暂停+chronobreak 回滚+规则不确定性"事件型崩盘；
  若 chronobreak 属实（官方裁定时光倒流），则"T1 优势被官方裁定抹掉"
  属于规则内事件，未必是假赛——定性必须等官方/复盘录像确认。

核查清单（后续逐项打勾）：
1. 官方/赛事方声明：G2 暂停次数、时长、chronobreak 裁定依据
2. 复盘录像：19:15 重启后的关键团战（T1 优势为何瞬间崩塌）
3. 同一时段其他平台盘口：是否有与暂停消息同步的异常大单
4. 虎牙弹幕：用户提供房间/录播链接后做暂停时段弹幕情绪分析
5. G3-G5 终局：T1 二队后续表现（若系列赛继续崩则强化"实力差"解释，
   若 DNS 后续被翻则强化"剧本"解释）

结论：待核查。未证实前按"疑似"处理；交易上的可操作结论：
  BO 比赛长时间暂停 + 评论区规则/回滚/假赛共识 -> 高位持仓（70c+）
  先减仓锁盈（暂停期价格阴跌但仍有流动性时），不赌重启方向。
```

## 案例 3：NAVI vs Team Heretics G1/G2（2026-08-17，LEC）

```text
状态：疑似观察（用户 + 弹幕共识强烈，无外部证据；实力差解释未排除）
背景：NAVI 强队 vs TH，赛前整场 NAVI 82.5c；用户观赛时弹幕大量讨论
  "TH 可能带着任务"。
行为证据：
  1. G1 TH 前期团战多次小优势（NAVI 63-67c 拉锯），但一直没打出来、
     也不控任何资源，最终完全输掉（23:28-23:30 NAVI 73c->88.5c 单波带走）；
  2. G2 TH 开局直接 0-3 送，赔率 30.5c -> 9c（6 分钟 -21.5c）；
  3. G2 中段 TH 追回 2 个头（5-2），但赔率完全不动（市场认定无反抗）。
赔率证据：G1 NAVI 63c->99.5c；G2 NAVI 65.5c->99.95c（开局即深水）；
  整场 82.5c->99.95c。
反向解释（未排除）：NAVI 实力明显强于 TH，赛前定价已 82.5c，
  "有优势不兑现"可能只是状态差/操作失误，假赛无法从赔率证实。
核查清单：
1. G1 复盘录像：TH 有优势时的团战决策（为何不控资源/不打）
2. G2 开局 0-3：具体死亡原因（送 vs 被单杀）
3. 弹幕归因：虎牙直播间 G1/G2 时段弹幕（用户确认可抓，待提供 vid）
4. TH 后续比赛：是否持续出现"有优势不兑现"行为
5. 盘口异动：G2 赛前 NAVI 65c 是否有大额买入（用户 320U 属散户级）
结论：待核查。交易可操作结论：强队对弱队 + 开盘 60-70c + 对手
  有优势不兑现 -> 按强者恒强执行（本场用户 65c 买 NAVI 95c 清仓=正样本），
  不因"弹幕任务论"反向操作。
```

## 获胜者拆解模板（假赛场次复盘）

```text
适用：对"明显假赛 / 高度疑似"场次的最终获胜者做详细拆解，沉淀可识别特征。
字段：
  获胜者 / 比分（小局明细）
  局内路径：怎么赢的（前期劣势翻盘 / 中期一波 / 对手送局）
  价格路径：获胜方与对手方各市场价格轨迹（低点 / 反弹 / 终局）
  市场资金：大额买单方向、时间点、钱包 / 账户（链上可查时）
  异常点：对手方行为异常（不打团 / 怪出装 / 送头）与解说提示
  定性状态：事实层（可证实）vs 定性层（需外部证据）
  关联特征：命中"假赛疑似通用信号"第几条
示例占位：EDG vs LGD（2026-08-14）拉盘场次——数据见 docs/forensics/data/fkigedgjdgwbg/，拆解待补。
```
