# 赛前预期情景（不打无准备的交易）

最后更新：2026-08-09

用法：每场比赛开赛前 5 分钟，用对战预判页 + 本模板列出 **3-5 个可能的价格走势情景**；
比赛结束后回填"实际走了哪个情景"，对照预期与执行，累积情景频率校准权重。

## 标准情景集（按联赛波动 / 实力差调整权重）

```text
S1 热门全程压制、无回撤     -> 低交易价值：不做（S2 挂单不触发 = 正常，别硬做）
S2 热门回撤到 45c 档        -> S2 主攻（🟢，45c 触发率最高）
S3 一方被砸深位（<30c/<15c）-> 彩票机器 / 强强对话价值买入（联赛信誉过滤，LPL/LEC/LCP 降级）
S4 90c+ 尾盘               -> D2 锁盈保护（不持仓过 90c+；高波动联赛 95c 快进快出）
S5 五五开开局一方碾压       -> 不早买（C2 变体反面，败方 44-53c 开局归零）
```

## 填写模板

```text
比赛 / 两队 / 赛前赔率（实力差）/ 联赛（查 LEAGUE_PROFILES）
预期情景清单：
  情景 | 概率权重 | 触发就做（策略 + 仓位 + 保护） | 不触发就不做
实际走势（赛后回填）：走了哪个情景？预期 vs 实际差异？执行是否到位？
```

## 示例：CFO vs GZ（LCP 高波动，BO5，2026-08-09）

```text
联赛画像：LCP 波动高、BO5 常打满 -> 单局快进快出、止盈要快、不延伸整场。
预期情景：
  S3 深蹲/错杀：任一方被砸 <30c -> 被砸侧反转；CFO 被砸看 GZ 反扑，GZ 被砸看 CFO 信号加仓
     （LCP 波动大，双方都可能出深位）。
  S2 回撤：CFO 50c 开局回撤到 35-40c 后回升 -> S1-标准中位，等信号（阿卡丽单杀）确认后加仓。
  S1 压制：任一方一路碾压无回撤 -> 不做。
  S4 尾盘：90c+ 快进快出，95c 止盈优先（高波动联赛不恋战）。
实际（回填）：CFO 50c 建仓 -> 19:27 35c 低点 -> 阿卡丽第一波单杀（信号）-> 95c 止盈 +90%。
  = 走了 S2+S3 组合，信号加仓生效；预期与实际一致，执行到位（与 BFX 98.5c 未止盈对照）。
```

## 复盘闭环

```text
每场情景与实际对照记录（复盘模板增加"预期情景 vs 实际"字段）-> 情景频率累计
-> 更新预判权重（与对战预判页自学习一致）；"没列到"的情景进未知形态通道。
```
