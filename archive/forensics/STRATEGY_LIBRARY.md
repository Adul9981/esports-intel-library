# 策略库：从交易者拆解中沉淀的可复制策略

最后更新：2026-08-17

本库登记从外部交易者（当前：e46m3）拆解出的、有可能被本项目复制的策略。
每条策略带证据、参数与成熟度。成熟度沿用项目框架：

```text
L0 观察 -> L1 建议 -> L2 回测/模拟 -> L3 小额实盘 -> L4 稳定实盘
未到 L2 之前只登记、只建议，不进入任何实盘路径。
```

## S-F1 完整集定价套利（Complete-Set Arbitrage）

核心：检测负风险多选项组的完整集定价 Σp 偏离 $1，买入被低估的一侧，
用 Convert/Merge 立刻兑现价差（不等结算）。

### 方向 A：Σp > 1（买 NO 组合 -> Convert）

```text
触发：Σp_YES > 1 + 阈值（吉达实测偏离 4.7%~6.4%，阈值待定）
步骤：
  1. 扫组内各档 YES 价格，计算 Σp；
  2. 以市价/限价买入 NO 组合（价格低于理论值 (1-p_i) 的档）；
  3. Convert：NO 组合 -> 现金 (n-1)X + 补集 YES；
  4. Merge 可配对的 YES+NO，或把补集 YES 卖出/留存；
  5. 循环，叠加做市返佣。
单轮毛利：≈ X × (Σp − 1)
```

证据（吉达 8/12 温度组，13 次 Convert）：

```text
每次 Convert 时点 Σp = 1.0475~1.0640
00:22:04 那笔：NO(35~41°C+ 共 7 档) -> YES(31~34°C 共 4 档) + $23.48 现金
链上交易：0x213f98a8867a9cc77a6c0fef36a2d2f91732070f2a9a9b0633ef06b3696a27f8
```

### 方向 B：Σp < 1（买 YES 完整集）

```text
触发：Σp_YES < 1（尚未在该地址数据中实测，观察中）
步骤：买入全套 YES（价格合计 < $1）-> 持有到结算 Redeem / 或组内 Merge
```

### 参数与风险

```text
适用市场：负风险多选项组（温度档、比分盘、冠军未来盘、选举）
观察参数：Σp 偏离阈值、单轮金额、循环频率、返佣贡献占比
e46m3 实测风格：单笔中位 $0.70，10-100 区间为主；全天 24×7
风险：
  1. 盘口薄 -> 买入价高于报价价（滑点吃掉价差）
  2. Σp 快速回归 -> 未及时出手则套利空间消失
  3. 结算前极端行情 -> 边缘档价格剧变
  4. 返佣依赖 -> 无返佣时毛利可能不覆盖成本
成熟度：L1 建议（1 个完整案例；升级 L2 需 ≥3 场 + Σp 回测）
```

## S-F2 做市返佣叠加（Rebate Farming）

```text
核心：在长尾市场 24×7 挂双边小单，赚做市/吃单返佣 + 平台奖励，Convert/Merge 用于清库存。
证据：e46m3 近 100 笔返佣+奖励合计 $2,546；活动 24 小时无空窗。
成熟度：L0 观察（返佣规则需平台文档确认；本项目当前不追返佣）
```

## S-F3 尘埃尾差清理（Dust 管理）

```text
核心：用极小额 Convert/Merge 清掉拆分/合并留下的尾差，保持仓位干净。
证据：e46m3 在 MLB 冠军盘 157 次转换中位仅 $0.02；吉达组穿插大量 ≤$0.01 操作。
价值：低（主要是卫生），不是利润来源；复制优先级最低。
成熟度：L0 观察
```

## 复制门槛与纪律

```text
1. 我们复制的是"现象 -> 规则"，不是照抄他的仓位与频率。
2. 任何 S-F 策略进入实盘前必须：≥3 场同模式案例 + Σp 回测通过 + 走项目成熟度/风控。
3. 执行仍遵守项目红线：方向无歧义、不碰私钥、固定金额制、先 dry-run。
4. 每场拆解结论必须回流本库：更新样本数、成熟度、参数或登记新模式。
```

### S-F1 复制可行性判断（2026-08-12）

```text
检测层（已具备）：Σp 实时计算、三案例（天气/足球/棒球）已验证，可建只读扫描器。
执行层（缺口）：
  1. Convert/Merge 是链上合约操作，当前 polydata 钱包项目只有买卖网格接口，
     无转换/合并能力；补齐需改 polydata（用户决策 + 显式授权）。
  2. 边很薄：单轮净利约 X 的 3%~7%（占投入资金约 0.5%~1.5%），依赖小单高频；
     流动性天花板低（目标账户单笔中位 $0.70），大资金会吃掉价差。
  3. 真实净盈利未完全证实：现有数字为估算（含返佣），需模拟验证。
升级前置（L1 -> L2）：
  1. 只读 Σp 扫描器跑两周，统计窗口频率/持续时间/可成交性；
  2. 用价格历史做模拟回测（买 NO @ 中间价 + Convert + Merge），
     计入滑点假设后看净期望；
  3. 回测为正、用户确认、风控放行后才进入执行开发与小额试点。

### S-F1 回测结果（2026-08-17，Step 2 已落地）

工具：tools/forensics_arb_backtester.py（价格历史重放 + 模拟 Convert/Merge，
按 ARB_SCANNER_EXEC_DESIGN §3.3 判定公式：买全套 NO → Convert → 现金 (n−1)X）。
报告：reports/forensics_arb_backtest_*.md。

```text
样本 1：吉达温度组（11 腿，2026-08-10 16:32Z ~ 08-11 16:31Z，1 分钟价格）
  Σp = 0.989~1.0835，≥1.02 时间占比 73.7%，独立错价窗口 31 个
  默认口径（X=$10、滑点 100bps、taker 费率 0.05、无返佣、gas $0.05）：
    31 轮，累计毛利 $8.32，摩擦 $27.18，净利 -$18.86（ROI -0.60%）
  摩擦分解：滑点 61%、taker 手续费 33%、gas 6%
  敏感性：滑点 0 + 返佣 100% -> +$6.77（唯一转正组合）；滑点 50bps 全组合为负
  阈值敏感性：entry 4% -> -$10.47；entry 5% -> -$6.71（仍为负）

样本 2：Villarreal C vs Levante UD 比分盘（17 腿，2026-08-04 19:30Z ~ 20:50Z）
  Σp = 0.957~1.0765，≥1.02 时间占比 86.4%，1 个长窗口
  默认口径：1 轮，毛利 $0.77，摩擦 $2.06，净利 -$1.29（ROI -0.80%）

现实校验（e46m3 链上活动）：
  吉达 13 次 CONVERSION、6 轮 NO 买入，全部集中在 Σp ≥ 1.0475（1.0475~1.0695），
  且只挑部分腿买（均价 0.68~0.94，低于全套标记均值 0.90）；另叠加做市/返佣。
  -> e46m3 的实际执行质量远好于"全腿 taker + 标记价 + 1% 滑点"的保守口径。
```

结论与门槛（2026-08-17）：

```text
1. 结构边真实存在（Σp 长期偏离、机会频率高），但厚度很薄：
   毛利约 (Σp−1)X，占投入资金仅 ~0.3%，1% 滑点即可吃掉大半。
2. taker 全收费、无返佣口径下回测为负 -> 按"回测不为正不模拟"纪律，
   S-F1 停留在 L1，不进入模拟/实盘路径。
3. 升 L2 的前置改为：
   a. 订单簿历史数据校准真实可成交成本（标记价 + 滑点假设精度有限）；
   b. 平台返佣/做市规则确认（S-F2，2026-08-15 实测 Convert 0 bps 只是第一步）；
   c. 用扫描器跑满两周，统计 Σp≥4%~5% 的窗口频率（e46m3 实际只吃这种）。
4. 若上述验证通过，参考口径：滑点 ≤50bps + 返佣覆盖手续费时才有正期望。
```
结论：流程可复制，利润不可保证；先用只读工具验证，再谈真实资金。
