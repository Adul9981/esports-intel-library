# Polymarket 电竞交易情报库（Esports Intel Library）

> 把 Polymarket 电竞市场的公开行情 + 主观情报（弹幕 / 解说）+ 历史数据，加工成**只给事实与统计、不给买卖建议**的情报库，为交易者的赛前决策提供数据支撑。

**最高原则：清清爽爽提供情报分析**——界面简洁、只给事实与统计、每条情报可溯源；无样本不硬撑（显示"样本不足"）、无信号不硬造（显示"今日无信号"）。

## 核心功能（三大块）

```text
1. 今日比赛：机会卡（信号 + 同形态统计 + 双方档案速览 + 风险）+ 形态气候（昨日定稿 + 今日滚动）。
2. 比赛情况：一个页面、状态驱动——未开赛 = 赛前档案卡 + 观察；
   进行中 = 6 块实时组件；已结束 = 结算 + 形态。
3. 比赛档案 / 情报库：四维查询（联赛 / 队伍 / 形态 / 策略）+ 反转统计视图 +
   假赛特征库与关注名单 + 弹幕集体智慧 + 陷阱反面样本 + 未知形态观察池。
```

## 边界与红线

```text
1. 只给情报与统计，不给交易建议；买卖决定与责任都在用户侧。
2. 网站不下单、不持有私钥；实盘执行与本库解耦。
3. 假赛内容一律"疑似 / 风险观察"标注，只给信号 + 依据 + 来源，不断言。
4. 弹幕 / 解说等主观数据只展示聚合结论与统计，不裸展示弹幕流与用户身份。
5. 所有统计标注样本量与时间窗口，小样本不伪装成高置信结论。
```
